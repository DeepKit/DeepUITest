# DeepGuide Showcase 展示愿景与蓝图

> 产品名：深导·展示 DeepGuide Showcase
> 定位：可视化展示任意能力旅程 + 内置 OCGS 教学场景
> 用户：任何人（售前演示 / 培训展示 / 管理者 / 工程师 / 研究者）

---

## 一句话定位

> **深导·展示是深导体系的可视化窗口，让任何人都能看懂一条业务旅程是怎么运行的。**

---

## 核心能力

```text
读取 Journey Schema / BusinessJourneyPackage
播放旅程步骤（逐步展示 Gate → Card → Route）
解释每一步为什么发生
展示 Gate / Trace / Treasure
切换角色视角（专家视角 / 新人视角 / 管理者视角）
```

---

## 内置教学场景（原"深演·明理"）

5 章固定教学场景，帮助新人看懂 OCGS：

```text
1. 能力裸奔     理解"能≠序"
2. 目的绑定     理解 Ability 为什么要绑定 Purpose
3. 合当约束     理解 Purpose≠Due
4. 高风险行为   理解 L3 需要确认/人工升级/禁止自动执行
5. 完整链路     看懂 Boundary→Ability→Gate→Trace→Version
```

教学场景使用与展示端相同的播放引擎，只是内容为内置固定场景。

---

## 用途

```text
售前演示：给客户展示"旅程包是怎么运行的"
培训展示：给新人展示"你将按什么路径工作"
治理效果可视化：给管理者展示"门禁和风险是怎么生效的"
OCGS 教学：让新接触者快速理解 OCGS 核心概念
```

---

## 与其他产品的关系

```text
展示端是编排端和陪跑端的可视化窗口
展示端只读，不修改旅程包
展示端调用底座 Runtime（只读播放模式）
```

---

## MVP 优先级

展示端不在 P0-P2 第一优先，建议后置到 P4；P0-P2 以 Protocol / Schema / Validator、Studio 最小写包端和 Coach 最小播放端为准。
