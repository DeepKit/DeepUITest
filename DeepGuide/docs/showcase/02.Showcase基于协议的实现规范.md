# Showcase 基于协议的实现规范

> 状态：开发收敛版
> 协议依赖：DeepGuide Journey Protocol v1.0

---

## 1. 定位

Showcase 是 Journey Package 的只读解释端，用于售前演示、培训展示、协议教学和结构调试。

Showcase 不修改旅程包，不产生业务执行 Trace，不执行真实风险确认。

---

## 2. 读取范围

Showcase 可以读取：

- `draft`：用于 Studio 预览。
- `reviewed`：用于审核讲解。
- `published`：用于售前、培训和教学。
- `recalled/deprecated/archived`：只读查看历史。

读取非 published 包时，界面必须明确标注状态，避免被误认为可执行版本。

---

## 3. 展示顺序

按协议对象展示：

1. Package 元信息和状态。
2. BoundarySet 和 AbilitySet。
3. Output。
4. Journey start_gate。
5. Gate。
6. GuideCard。
7. RouteRule。
8. RiskPolicy / LostRecovery。
9. CompletionGate 和 Output 达成条件。

---

## 4. 解释模式

| 模式 | 展示内容 |
|---|---|
| 新人视角 | 主路径、图卡、选择项、恢复路径 |
| 专家视角 | Gate/Card/Route/Condition/Risk 完整结构 |
| 管理视角 | 风险、发布治理、Trace 要求、召回策略 |
| 开发视角 | JSON 路径、引用关系、Validator 规则 |

---

## 5. 只读约束

- 不修改任何 Package 字段。
- 不触发真实 RiskPolicy 确认。
- 不写业务 TraceEvent。
- 可以写独立的浏览分析日志，但不得混入 Coach 执行 Trace。

---

## 6. 内置教学场景

Showcase 可以内置 OCGS 教学包，但教学包也应采用 Journey Package 结构，避免出现“演示内容和真实协议不一致”。
