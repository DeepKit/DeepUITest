# 行业配置包 — 后继问题讨论

---

## 待讨论问题

1. 配置包的技术格式：JSON 文件包 vs 数据库配置 vs 两者都支持？
2. 配置包的版本管理机制？
3. 第三方 ISV 如何制作和提交行业配置包？
4. 配置包市场/商店是否需要？
5. 行业术语映射的维护流程（谁负责更新）？
6. 深用/深客作为 L2 二级底座，它们的配置包与其他行业配置包的区别是什么？

---

## 已确认决策

- 行业分版降级为配置包，不是独立产品
- 新增行业 = 新增配置包，不改底座代码
- 深用/深客是第一梯队自研直营
- 第三梯队通过渠道/集成商落地
- 对外命名统一为 DeepGuide for + 行业名
- 首个参考行业：财税/会计实操
- 首个样板业务：发票报销材料检查
- 首个样板角色：新入职财务助理 / 报销初审员
- 财税样板只做导航，不做税务结论裁判，不采集证据链
