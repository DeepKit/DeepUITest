# DeepGuide Studio PRD 功能模块

> 来源：OCGS.079 Studio 编排中心 PRD
> 版本：v0.1 草案

---

## 功能模块清单

### 工作台首页

显示：我的旅程包、最近编辑、待审核、已发布、已废弃、一线卡点反馈、版本更新提醒。

### 旅程包管理

支持：新建、复制、编辑、删除草稿、归档、发布、召回、废弃、新建版本、版本对比。

### 宝物定义器

字段：OutputKey、OutputName、FinalState、RiskLevel、CompletionCheckRequired、CompletionGate、适用角色、适用业务场景。

### AI 主持式门禁倒推器

功能：AI 提问 → 数字候选 → 人类选择 → 自动记录 HumanDecisionLog → 生成负号门链 → 门类型标注 → 粒度检查。

硬要求：不能从入口顺推，必须从宝物倒推。

### 场域/门禁编辑器

支持 Field、Gate、Condition、Route、Risk、Recovery、Trace 编辑。

### 图卡编辑器

图卡类型：文本说明卡、场域示意卡、线框导航卡、聚焦线框卡、问答选择卡、风险确认卡、完成验证卡。

### 视觉锚点编辑

支持：线框图、模糊化背景、聚焦目标、色框、导航线、目标字段/按钮/区域标注。视觉锚点只用于 Coach B 图卡展示区的参考导航，不用于自动点击或证据链采集。生成方式为 AI 和专家讨论，AI 负责画定，专家动口不动手，通过口头确认和修正完成。确认粒度为流程节点，一图一认。

### 意图触发语编辑器

配置：触发语、同义说法、实体抽取、置信度阈值、不确定时反问、关联 Journey。

### LostRecovery 编辑器

每个关键卡点配置：用户问题、可能原因、数字候选、路由目标、是否需要专家、是否留痕。

### 风险策略编辑器

配置：RiskLevel、风险说明、是否确认、是否二次确认、是否可回滚、是否强制留痕、是否禁止自动执行。

### 测试中心

测试：正常路径、分支路径、迷路恢复、风险确认、无效输入、权限不足、版本兼容、运行环境兼容（首版 Windows 10/11、高 DPI、多屏；Win7 仅项目制兼容）。

### 审核发布中心

流程：草稿 → 自检 → 专家审核 → 合规审核 → 发布 → 前台可用。

---

## 关键界面

- 旅程包列表页：名称、业务域、版本、状态、负责人、使用次数、卡点数量
- 宝物定义页：宝物名称、完成状态、风险等级、完成检查项、完成门
- 倒推门禁页：左侧负号门链，中间当前门详情，右侧 AI 主持提问与 HumanDecisionLog
- 图卡编辑页：左侧流程节点/图卡列表，中间线框图画布/文本，右侧属性/路由/风险/恢复/视觉锚点/确认状态
- 测试页：红绿灯状态、缺失项、断路、高风险未确认、无恢复路径
