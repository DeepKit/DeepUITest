# DeepGuide Studio 编排中心 — 后继问题讨论

---

## 待讨论问题

1. Studio 的技术栈选择：Web 端 vs 桌面端 vs 两者都做？
2. AI 主持式倒推的 Prompt 模板是否需要标准化？
3. 图卡编辑器是否需要支持拖拽式可视化编排？
4. 多人协作编辑旅程包的冲突处理机制？
5. 旅程包的导入/导出格式（JSON? YAML? 专有格式?）

---

## 已确认决策

- 必须从 Output 倒推，不从入口顺推
- 所有前台候选使用 0-9 数字语法，并保留 0 作为返回/取消
- 红绿灯机制：红色不可发布
- MVP 暂不做复杂企业权限和多组织租户
