# DeepGuide Studio 编排中心愿景与蓝图

> 产品名：深导·编排 DeepGuide Studio
> 定位：企业业务旅程编排中心
> 用户：业务专家 / 流程负责人 / 培训负责人 / 合规负责人

---

## 一句话定位

> **Studio 负责"造旅程包"，Coach 负责"播旅程包"。**

---

## 产品目标

把专家经验变成结构化的 BusinessJourneyPackage，经审核后发布给 Coach 使用。

---

## 核心能力

```text
1. 宝物定义器 — 定义 Output / FinalState / RiskLevel
2. AI 主持式门禁倒推 — 从 Output 倒推，不从入口顺推
3. 场域/门禁/图卡编辑器 — 编排完整旅程结构
4. 风险策略编辑器 — 配置 L0-L3 风险规则
5. LostRecovery 编辑器 — 配置迷路恢复路径
6. 意图触发语编辑器 — 配置用户说法与匹配规则
7. 测试中心 — 红绿灯机制，路由完整性检查
8. 审核发布中心 — 草稿 → 自检 → 专家审核 → 合规审核 → 发布
9. 版本管理 — 发布/召回/废弃/新版本/版本对比
```

---

## 核心工作流

```text
新建旅程包 → 定义宝物 → AI 主持式倒推门禁 → 编排图卡
→ 配置路由/风险/恢复 → 测试（红绿灯）→ 审核发布
```

---

## 图卡视觉规则

图卡应尽量和员工正在操作的真实业务界面结构一致，但表达形态以线框图为主。Studio 图卡编辑器需要支持线框图、模糊化、聚焦化、色框和导航线。

```text
粉红实线  当前主焦点
粉红虚线  候选目标
浅蓝      场域
浅绿      成功状态
浅黄      风险区
灰色      弱化背景
导航线    连接说明文字、数字候选和界面目标
```

图卡不是抽象流程图，也不是系统截图覆盖层，而是员工现场操作界面的线框参考导航图。

视觉锚点的生成方式是：AI 和专家讨论，AI 负责在线框图上画定色框、导航线、模糊区和聚焦区；专家动口不动手，只通过口头确认、否定和修正来完成审核。确认粒度按流程节点执行，一图一认。

---

## 红绿灯机制

- 绿色：可发布
- 黄色：有轻微问题，可审核后发布
- 红色：关键缺失，不可发布

红色示例：没有 Output、没有 CompletionGate、Route 断裂、高风险无确认、候选无数字、正常路径无法到达 Output。

---

## 角色权限

```text
超级管理员：系统配置、全局发布、旅程记录查看
业务专家：创建/编辑旅程包、定义宝物、提交审核
审核员：审核内容/风险/发布、要求修改
培训负责人：查看使用情况、查看卡点、提出优化
只读观察者：查看旅程包和统计
```

---

## MVP 范围

第一版只做：旅程包创建、宝物定义、AI 主持式门禁倒推、图卡编辑、数字候选配置、路由配置、LostRecovery、风险确认、基础测试、发布给 Coach。

暂不做：复杂企业权限、多组织租户、大规模 BI、自动生成完整旅程、RPA 自动执行。
