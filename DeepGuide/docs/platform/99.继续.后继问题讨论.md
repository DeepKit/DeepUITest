# DeepGuide Platform 通用底座 — 后继问题讨论

---

## 待讨论问题

1. Journey Schema 是否需要支持"场景继承"（子旅程包继承父旅程包的公共门禁）？
2. Runtime 的部署形态：嵌入式 SDK vs 独立微服务 vs 两者都支持？
3. AI Layer 第一阶段是否只做规则匹配（不做 LLM 生成）？
4. Industry Adapter 的配置包格式是否需要标准化为可导入/导出的 JSON 包？
5. Validator 的 DryRun 是否需要支持"模拟用户选择序列"自动化测试？

---

## 已确认决策

- 底座不直接面向用户销售，通过产品端间接服务
- AI 只引用已审核内容，不编造业务规则，不跳过风险门禁
- 风险级别 L2/L3 必须确认，L3 必须留痕
