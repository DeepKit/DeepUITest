# 产品愿景

## 一句话

**小序私域助手：每天帮你发朋友圈、聊客户、促成交、要转介绍。**

内部项目名为 **序枢 DeepAxis**。对外首版产品可使用更轻的名字，例如“小序私域助手”。

## 为什么不是企业微信

企业微信适合企业资产沉淀、组织管理和合规运营，但早期销售路径较重：

```text
找老板 -> 讲 ROI -> 走流程 -> 接系统 -> 培训团队 -> 交付
```

当前目标是快速自成交、低价裂变、个人传播，因此首发应选择个人微信场景：

```text
个人微信 -> 朋友圈 -> 私聊 -> 微信群 -> 转介绍 -> 裂变付费
```

## 产品本质

DeepAxis 首发不是 CRM，也不是 Agent Framework，而是一个个人微信销售副驾：

```text
用户自己卖产品
  -> 不知道发什么
  -> 不知道怎么聊客户
  -> 不知道怎么跟进
  -> 不知道怎么要转介绍
  -> DeepAxis 每天给作战卡、话术、内容和提醒
```

## 长期愿景

短期是个人微信私域销售助手。

中期是私域成交项目平台：

- 用户用它提升成交。
- 推广员用它推广产品。
- 服务商用它组织区域社群和培训。
- 平台沉淀行业话术、客户状态、裂变路径和成交模板。

长期可回到 ASTO Business Agent Runtime：

```text
个人销售数据
  -> 客户状态
  -> 跟进动作
  -> 成交反馈
  -> 行业定向维
  -> 更智能的私域增长运行时
```

## 核心用户

首批用户不是企业 CIO，而是靠个人微信成交的人：

- 微商。
- 私域团长。
- 知识付费销售。
- 教培课程顾问。
- 美业顾问。
- 养生健康产品销售。
- 本地生活私域运营。
- 副业卖货人。

## 核心承诺

产品不承诺“躺赚”，只承诺降低日常私域销售的执行摩擦：

- 今天发什么。
- 今天跟谁。
- 客户说贵怎么回。
- 怎么让老客户转介绍。
- 怎么把一次成交变成复购和裂变。
