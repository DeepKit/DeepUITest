# 分利与合规边界

## 当前分利方案

推荐采用四类角色：

```text
平台
  -> 服务商
  -> 推广员
  -> 用户
```

组织上可以记录省、市、县等区域服务关系，但财务上不做逐单自动多级分佣。

## 基础分配

以 99 元年卡为主商品时，建议：

```text
平台基础池：10%
服务商基础服务费：20%
服务商奖励池：最高 20%
推广员直推佣金：50%
```

其中服务商奖励池不是自动分佣，而是平台按月或按季度根据统计数据单独发放。

## 服务商奖励池

服务商基础服务费：

```text
保底 20%
```

额外奖励：

```text
县区服务奖：最高 10%
城市服务奖：最高 6%
省级服务奖：最高 4%
```

这些奖励只在后台统计资格，不在订单发生时自动分给多层上级。

## 平台收益

平台基础池为 10%，但以下未释放收益归平台：

- 没有服务商关系的服务费。
- 没达到资格的区域奖励。
- 投诉、退款、作弊导致扣回的奖励。
- 高阶产品收益。
- 训练营、行业包、陪跑产品的平台分成。

因此早期平台实际收益可能高于 10%。

## 资格统计口径

不要用“伞下人数”作为唯一标准。

应使用：

```text
有效付费用户数
用户活跃率
续费率
退款率
投诉率
培训/答疑次数
真实使用记录
成交案例数
```

建议示例：

```text
县区服务奖：有效付费用户 >= 300，30 日活跃率 >= 40%
城市服务奖：有效付费用户 >= 2000，30 日活跃率 >= 35%
省级服务奖：有效付费用户 >= 10000，30 日活跃率 >= 30%
```

具体阈值应根据首批数据调整。

## 角色说明

### 平台

负责：

- 产品开发。
- AI 成本。
- 支付结算。
- 内容模板。
- 活动策划。
- 风控。
- 客服。
- 奖励发放。

### 服务商

负责：

- 区域社群运营。
- 用户培训。
- 推广员答疑。
- 案例收集。
- 活跃和续费维护。

服务商领取的是服务收益和区域奖励，不是单纯下级人头收益。

### 推广员

负责：

- 直接推广成交。
- 分享海报。
- 私聊推荐。
- 朋友圈种草。

推广员只拿直接成交佣金。

### 用户

负责：

- 购买和使用产品。
- 自己销售自己的产品。
- 可自愿推荐产品。

用户不是分销层级的资源。

## 红线

以下事项禁止：

- 交钱买资格。
- 囤货。
- 按下级人数发钱。
- 承诺躺赚。
- 发展无限层级。
- 自动多级分佣。
- 诱导分享。
- 诱导关注。
- 自动加好友、群发、私聊。
- 微信协议号、Hook、群控。

## 推荐表达

对外不要说“省代、市代、县代层层分钱”。

推荐说：

> 推广员拿直推佣金，服务商拿服务费，区域服务奖励由平台根据真实付费、活跃、续费和服务质量按月发放。

## 合规原则

1. 奖励真实产品购买，不奖励纯拉人头。
2. 奖励真实服务交付，不奖励空挂层级。
3. 所有收益可追溯到订单、用户使用和服务动作。
4. 不做自动多级分佣。
5. 不做强制购买资格。
6. 不宣传静态收益和躺赚。
