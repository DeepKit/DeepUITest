# 自己吃自己与裂变体系

## 核心原则

DeepAxis 必须自己使用自己的产品完成增长。

这意味着：

```text
产品每天给用户销售动作
用户用动作销售自己的产品
用户也可以用同一套动作销售 DeepAxis
DeepAxis 的裂变素材由 DeepAxis 自己生成
推广员的作战卡也由 DeepAxis 每天生成
```

## 增长闭环

```text
用户进入小程序
  -> 生成今日作战卡
  -> 复制朋友圈/私聊话术
  -> 在个人微信发布
  -> 朋友扫码体验
  -> 付费成为会员
  -> 推广员获得直推收益
  -> 用户继续用产品成交和推广
```

## 三条裂变循环

### 1. 内容裂变

用户生成可传播内容：

- 私域成交力评分。
- 7 天朋友圈成交日历。
- 客户说太贵怎么办话术卡。
- 本周客户跟进清单。
- 行业爆款朋友圈模板。

这些内容带有用户邀请码和产品水印。

### 2. 任务裂变

每日作战卡加入裂变任务：

```text
邀请 1 人体验 -> 解锁行业话术包
邀请 3 人付费 -> 送 1 个月会员
邀请 10 人付费 -> 升级年度会员
完成 30 单直推 -> 申请服务商资格
```

### 3. 收益裂变

用户自己用产品赚钱，也能推广产品赚钱。

```text
用户发现产品有用
  -> 推荐给同行/朋友
  -> 获得直推收益
  -> 形成推广习惯
  -> 进入服务商体系
```

## 价格梯度

| 产品 | 价格 | 作用 |
| --- | ---: | --- |
| 免费版 | 0 元 | 拉新体验，生成基础文案和话术 |
| 月卡 | 9.9 元/月 | 低门槛付费，验证购买意愿 |
| 年卡 | 99 元/年 | 裂变主商品，适合返佣 |
| 服务商版 | 199 元/年 | 获得推广素材、收益看板和服务商申请资格 |
| 训练营/行业包 | 399-999 元 | 利润产品，承接高意愿用户 |

## 首推商品

裂变主商品建议是 **99 元年卡**。

原因：

- 9.9 元月卡客单太低，推广员动力弱。
- 99 元年卡足够低价，冲动购买阻力小。
- 99 元年卡可给推广员 50% 直推佣金。
- 年卡能减少续费摩擦，便于裂变统计。

## 作战内容示例

每日作战卡示例：

```text
今天发 2 条朋友圈：
1. 信任型：讲一个客户变化案例
2. 裂变型：送一份行业话术卡

今天私聊 5 个老客户：
话术：最近我整理了一个成交话术包，你要不要拿一份？

今天完成 1 个转介绍动作：
话术：你身边有没有也靠微信卖货、但每天不知道发什么的人？
```

## 自己吃自己的组织动作

平台每天也用 DeepAxis 生成：

- 平台朋友圈素材。
- 服务商培训话术。
- 推广员私聊话术。
- 用户案例复盘。
- 活动裂变海报。
- 社群打卡任务。

内部运营也按产品的每日作战卡执行。
