# 产品定义与架构

## 准确定义

DeepAxis 首发形态是：

> 面向个人微信私域销售的 AI 销售副驾，帮助用户生成内容、组织客户跟进、设计裂变动作，并通过微信生态完成低价付费和推广传播。

它不是：

- 个人微信自动化工具。
- 微信群控工具。
- 企业 CRM。
- 企业微信 SCRM。
- 通用 Agent 平台。
- 通用 Workflow 引擎。

## 推荐产品形态

首发建议做微信小程序或 H5，而不是独立 App。

```text
微信小程序 / H5
  -> 会员付费
  -> 邀请码
  -> 每日作战卡
  -> 朋友圈文案
  -> 私聊话术
  -> 客户跟进
  -> 裂变海报
```

个人微信负责人工传播与成交：

```text
DeepAxis 生成内容
  -> 用户复制
  -> 用户手动发朋友圈/私聊/微信群
  -> 用户把客户反馈贴回系统
  -> DeepAxis 给下一步动作
```

## 核心模块

### 1. 今日作战卡

每天给用户一张销售执行卡：

- 今天发什么朋友圈。
- 今天私聊谁。
- 今天怎么促单。
- 今天怎么要转介绍。
- 今天要完成几个裂变动作。

### 2. 朋友圈内容生成

按行业和目标生成：

- 信任型朋友圈。
- 成交型朋友圈。
- 裂变型朋友圈。
- 案例型朋友圈。
- 价值输出型朋友圈。

### 3. 私聊话术生成

支持常见场景：

- 初次破冰。
- 客户犹豫。
- 客户说太贵。
- 客户已读不回。
- 老客户复购。
- 请求转介绍。

### 4. 客户轻管理

不是重 CRM，只保留最小客户状态：

```text
新客
意向
犹豫
待跟进
已成交
复购
转介绍
沉默
```

### 5. 裂变海报与邀请码

每个用户有自己的推广码：

- 分享海报。
- 私域成交力评分卡。
- 朋友圈成交日历。
- 行业话术卡。
- 邀请收益页。

### 6. 会员与收益中心

用于承载“自己吃自己”：

- 我的会员。
- 我的邀请。
- 我的收益。
- 我的推广素材。
- 我的服务商等级。

## 数据对象

```text
User                  用户

InviteCode            邀请码

ServiceProvider       服务商
CustomerLite          轻量客户记录
DailyActionCard       每日作战卡
ContentTemplate       内容模板
ChatScript            私聊话术
GrowthPoster          裂变海报
RewardLedger          收益流水
QualificationMetric   服务商资格统计
```

## 微信边界

产品只提供 AI 生成、记录、提醒和复制，不直接控制用户个人微信。

允许：

- 生成朋友圈内容。
- 生成私聊话术。
- 生成裂变海报。
- 生成微信群运营素材。
- 提醒用户手动跟进。
- 用户手动复制客户反馈给 AI 分析。

不允许：

- 自动加好友。
- 自动群发。
- 自动私聊。
- 自动拉群。
- 个人微信协议登录。
- Hook 微信客户端。
- 批量养号。
- 群控。
