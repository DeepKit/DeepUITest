# DeepGuide for Delphi 愿景与蓝图

> 产品名：深导·Delphi DeepGuide for Delphi
> 定位：Delphi 项目的能力治理与窗体减肥
> 用户：Delphi 开发者
> 来源：原 OCGS-Delphi + ActionGrid

---

## 一句话定位

> **让 Delphi 项目的窗体不再膨胀，让功能入口有序可治理。**

---

## 解决的问题

```text
窗体膨胀 — 一个 Form 几千行代码
TAction / 按钮 / 菜单 / Event 混乱 — 功能入口写死在 UI 代码中
路由无法热更新 — 功能可见性/可用性硬编码
老项目难维护 — 改一个按钮影响一片
AI 生成 Delphi 代码难治理 — 生成后缺少结构化管理
```

---

## 核心能力

```text
ActionGrid — 轻量动作治理结构
  把动作从窗体代码中抽离
  管理动作可见性、可用性、路由
  与原生 TAction 融合
  渐进式接入老项目

OCGS Runtime Delphi 实现
  Field / Gate / Route / Trace 在 Delphi 中的运行时

窗体能力治理
  从事件肥胖到 OCGS Tier 2 结构化

符合性测试（Conformance Test）
  验证窗体是否符合 OCGS 治理规范
```

---

## 重要修正

OCGS-Delphi 不只解决老项目，所有 Delphi 项目都可以用。新项目从一开始就可以按 OCGS 结构组织能力。

---

## 与深导体系的关系

深导底座在 Delphi 工程领域的垂直实现。ActionGrid 是 OCGS 的早期前身之一，也可独立作为轻量方案。
