# ActionGrid 技术规格

## 1. 定位

ActionGrid 是 OCGS-Delphi 的核心组件，提供轻量动作治理结构。

## 2. 核心概念

- **ActionItem**：动作项，最小执行单元
- **ActionGroup**：动作组，逻辑分组，可嵌套
- **Visibility 规则**：条件表达式决定动作是否可见
- **Availability 规则**：条件表达式决定动作是否可用
- **Route 规则**：动作执行后的跳转目标

## 3. ActionItem 字段

| key | string | 唯一标识 |
| caption | string | 显示文本 |

## 4. ActionGroup

- 逻辑分组，对应 UI 上的工具栏区域/菜单分组
- 支持嵌套（Group 内含 Group）
- 组级别可设置整体 Visibility

## 5. Visibility 规则

- 条件表达式决定动作是否可见
- 替代硬编码 if-then 控制显隐
- 示例：user.role = 'admin'  显示管理操作

## 6. Availability 规则

- 条件表达式决定动作是否可用（启用/灰色）
- 示例：ecord.status = 'draft'  启用编辑按钮
- 不可用时 UI 显示为灰色，不可点击

## 7. Route 规则

- 动作执行后跳转到哪个状态/页面/下一步
- 支持条件路由：根据执行结果走不同路径
- 示例：保存成功  列表页，保存失败  停留当前页

## 8. 与 TAction 的融合

- ActionGrid 可包装原生 Delphi TAction
- 渐进式接入：先包装，再逐步迁移逻辑到规则引擎
- 包装后的 TAction 自动获得 Visibility/Availability 规则能力

## 9. 热更新

- Visibility / Availability / Route 规则可从配置文件加载
- 修改规则不需要重编译程序
- 支持运行时刷新规则

## 10. 渐进式接入老项目

- 不需要一次性重构
- 可以逐个窗体接入 ActionGrid
- 未接入的窗体继续使用原有 TAction 机制
- 接入顺序建议：高频窗体优先

## 11. 与 OCGS Runtime 的关系

ActionGrid 是 OCGS Gate/Route 在 Delphi UI 层的具体实现：
- ActionItem  Gate 的触发入口
- Route 规则  OCGS Route 的 UI 层映射
- Visibility/Availability  Gate 前置条件的 UI 表现

## 12. 符合性测试

- 检查窗体是否所有动作都通过 ActionGrid 管理
- 覆盖率指标：已接入动作数 / 窗体总动作数
- 目标：核心窗体 100% 覆盖
