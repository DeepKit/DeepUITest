# OCGS-Delphi 产品愿景与蓝图

> 产品名：深导Delphi DeepGuide for Delphi
> 定位：Delphi 项目的能力治理与窗体减肥
> 用户：Delphi 开发者
> 来源：原 OCGS-Delphi + ActionGrid

---

## 一句话定位

让 Delphi 项目的窗体不再膨胀，让功能入口有序可治理。

---

## 解决的问题

- 窗体膨胀：一个 Form 几千行代码
- TAction/按钮/菜单/Event 混乱：功能入口写死在 UI 代码中
- 路由无法热更新：功能可见性/可用性硬编码
- 老项目难维护：改一个按钮影响一片
- AI 生成 Delphi 代码难治理：生成后缺少结构化管理

---

## 核心组件

### ActionGrid - 轻量动作治理结构

- 把动作从窗体代码中抽离
- 管理动作可见性、可用性、路由
- 与原生 TAction 融合
- 渐进式接入老项目
- 降低窗体肥胖症

### OCGS Runtime Delphi 实现

- Field / Gate / Route / Trace 在 Delphi 中的运行时
- 可加载 Journey Protocol 定义的旅程包（可选集成）
- 纯 Pascal 实现，无外部依赖

### 窗体能力治理

三个层级（Tier）：
  Tier 0: 原始状态（事件直接写在窗体中）
  Tier 1: ActionGrid 接管（动作抽离，路由可配置）
  Tier 2: OCGS 完整治理（Field/Gate/Route/Trace）

### 符合性测试（Conformance Test）

- 验证窗体是否符合 OCGS 治理规范
- 检查：动作是否注册、路由是否可达、门禁是否配置
- 与深测协作：深测测试 UI 行为，符合性测试检查治理结构

---

## 重要原则

- 不只服务老项目，所有 Delphi 项目都可用
- 渐进式接入：不要求一次性重构
- ActionGrid 可独立使用，不强制完整 OCGS
- 与深测配合：深测测试行为正确性，Delphi 治理结构正确性

---

## 技术方案

语言：纯 Object Pascal
兼容：Delphi 10.x+ / FMX / VCL
依赖：无外部依赖
集成：可选集成 Journey Protocol（加载 JSON 旅程包）
测试：内置符合性测试框架
