2KeyRun 双键快启

按两下键，启动任何程序。
不翻菜单、不等搜索、不用鼠标。装了就回不去。

⬇ 免费下载 📖 使用文档
2KeyRun 主界面 — 左侧程序导航树 + 右侧 60 格键盘映射网格 + 底部控制面板。深色主题，科技蓝强调色。

它不是又一个搜索框

其他启动器让你打字搜索。2KeyRun 让你用肌肉记忆——和按电视遥控器一样简单。

🚀

分层网格快启 — 核心中的核心

4 层 × 60 格 = 240 个快捷槽位。键盘布局直接映射到屏幕：QWERTY 行就是第三行格子。开启单键模式后，按一个字母键直接启动——不需要 Ctrl+Q，就是一个键。把 exe 拖到格子上即完成绑定。

🔍

聚合搜索 — 没绑定的也能秒找

一个搜索框同时查三源：已绑定动作 + 系统已安装程序 + Everything 全盘文件。支持拼音首字母、全拼、中文、英文。输入 wx → 微信，chrome → 浏览器。2 个字母触发搜索，不等回车。

🌲

程序导航树 — 你的软件自动整理好了

首次打开即自动扫描所有已安装程序，按 13 个大类自动分类。最近使用、常用文件、常用目录各自独立标签页。内嵌文件浏览器，点文件就能打开。

⌨️

全局热键 — 手不离开键盘

F1 一键唤出，再按隐藏。任何界面、任何软件、任何状态下都能呼出。系统托盘常驻，不占任务栏空间。搜索框获焦自动切英文输入法——这个细节每天帮你省无数次切换。

📋

剪贴板增强 — 低调但救急

后台自动记录剪贴板历史，复制过的东西不会丢。中途覆盖了 A 内容？点历史列表就能找回。支持文本、链接等常用格式。

🎨

30 套主题 — 看着舒服才能用得住

深色 15 套 + 浅色 15 套。设置中实时预览、一键切换，无需重启。默认暗蓝黑 + 科技蓝强调色，和 Windows 暗色模式完美搭配。

🖱️

拖放操作 — 不是功能，是直觉

拖 exe 到空格子 → 绑定。拖 A 格到 B 格 → 互换。拖格子到常用文件树 → 收藏。全部操作遵循 Windows 用户的本能。

💡

配置分享 — 肌肉记忆应该可以带走

一键导出全部 Grid 布局为文件。换电脑、重装系统、帮同事配置——导入文件，秒级复现整个工作环境。所有数据存本地 SQLite，不依赖网络。

为什么不是又一个 PowerToys Run / Wox / uTools？

那些是「搜索框」逻辑——先想名字、再打字、再看结果、再点。2KeyRun 是「遥控器」逻辑。

你知道 Q 是微信，按 Q 就是微信。
你知道 W 是浏览器，按 W 就是浏览器。
不需要搜索、不需要选择、不需要确认。
眼睛看一次，手指记住一辈子。
