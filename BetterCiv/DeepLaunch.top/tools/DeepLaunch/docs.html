使用文档

快速上手 2KeyRun，掌握所有快捷键和操作技巧。

快速上手

第一步：启动

下载并解压后，运行 TwoKeyRun.exe。程序会自动缩小到系统托盘，不占用任务栏空间。

第二步：唤出主界面

按下 F1 或 F3 键唤出 2KeyRun 主窗口。再按一次则隐藏。

第三步：绑定你的第一个程序

将任意 .exe 文件或快捷方式从文件管理器拖到网格中的任意空格，即完成绑定。之后在单键模式下按对应字母键即可启动。

第四步：搜索一切

点击「搜索面板」标签，在搜索框中输入程序名称（中文、拼音首字母或英文均可），从结果列表中点击或回车启动。

Grid 网格操作指南

网格布局

主界面右侧的网格区域为 10 列 × 6 行 = 60 格。每个格子可以绑定一个程序，显示其图标和名称。

通过底部控制面板的「Grid 层级」可以在 4 层之间切换：

  • 无修饰层（none）：默认层，直接按键启动
  • Shift 层：Shift + 按键启动
  • Ctrl 层：Ctrl + 按键启动
  • Alt 层：Alt + 按键启动

总计 4 × 60 = 240 个快捷槽位。

单键模式

在底部控制面板勾选「单键模式」后，无需按任何修饰键，直接按字母或数字键即可启动对应格位的程序。

关闭单键模式后，按键输入会进入搜索框，不会触发程序启动，避免误操作。

拖放操作

  • 从文件管理器拖入：将 exe / lnk / bat / cmd / ps1 / url 文件拖到空格子上，自动绑定
  • 格子间互换：拖动一个格子到另一个格子上，交换两个格子的内容
  • 拖到左侧树：将格子拖到左侧「常用文件」树节点，加入收藏
  • 右键编辑：右键格子 → 编辑，手动设置程序路径、名称、启动参数

双击与 Enter

在网格中双击格子或选中格子后按 Enter，立即启动该程序。单击仅选中，不启动。

搜索技巧

搜索源

2KeyRun 的搜索框同时从以下来源检索：

  • 已绑定的快捷动作：你在 Grid 中绑定的所有程序
  • 系统已安装程序：自动扫描开始菜单和桌面建立的程序索引
  • Everything 全盘文件：需安装 Everything，开启后在设置中启用

匹配规则

  • 拼音首字母：输入 wx 可匹配「微信」
  • 全拼：输入 weixin 也可匹配
  • 中文：直接输入「微信」
  • 英文：输入 chrome 匹配 Chrome 浏览器
  • 全字匹配：多字符查询只匹配连续子串，不会拆分到不连续位置

触发条件

输入 2 个拉丁字符或 1 个中文字符后自动开始搜索。空输入框时显示最近使用记录（MRU）。

剪贴板增强

在设置中开启「启用剪贴板伴生进程」后，2KeyRun 会在后台监听剪贴板变化：

  • 自动记录每次复制的内容到历史列表
  • 在「剪贴板」标签页中查看历史记录
  • 点击任意一条即可粘贴到当前应用

主题切换

点击底部「设置」按钮，进入「外观」标签页：

  • 浅色系和深色系各 15 套主题
  • 点击主题名称即时预览，无需重启
  • 推荐默认深色主题以匹配系统暗色模式

常见问题

Q: 程序启动后找不到窗口？

A: 2KeyRun 默认最小化到系统托盘（右下角图标区）。按 F1 或双击托盘图标即可唤出。

Q: 输入中文时总是变成英文？

A: 这是「自动切英文输入法」功能，防止搜索时误输入中文。可在设置中关闭此功能。

Q: 搜索不到某个已安装的程序？

A: 在设置中点击「重建程序索引」，系统会重新扫描开始菜单和桌面。完成后即可搜索到新安装的程序。

Q: 如何完全退出程序？

A: 右键系统托盘图标 → 退出，或在主窗口底部点击「退出」按钮。

Q: 配置文件在哪里？

A: 所有配置和 Grid 数据存储在程序目录下的 data\ 文件夹中（SQLite 数据库）。备份该文件夹即可迁移全部配置。
