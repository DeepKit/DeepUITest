DeepConfig

深配

配置可视化，用户不迷糊

它做什么

配置文件对开发者来说是日常，但对普通用户来说是噩梦。DeepConfig 把任意格式的配置文件变成可视化的树形界面，让非技术用户也能安全地修改配置。

核心功能

树形浏览

支持 JSON、YAML、TOML、INI 等常见格式，自动解析为可折叠的树形结构。

内置 Python 脚本

配置变更时可触发 Python 脚本执行验证、转换或联动操作。

分发客户端

打包为独立可执行文件分发给用户，无需安装 Python 或其他依赖。

  • 配置模板：预定义字段类型和取值范围
  • 变更历史：每次修改自动备份
  • 校验规则：防止用户输入非法值
  • 多语言界面支持
