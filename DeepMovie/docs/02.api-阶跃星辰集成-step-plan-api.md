# 阶跃星辰 API 集成

## 基础配置

- **Base URL**: `https://api.stepfun.com/step_plan/v1`
- **认证方式**: Bearer Token（Header: `Authorization: Bearer <key>`）
- **协议**: OpenAI 兼容（Chat），自定义协议（Audio/Image）

## DeepBase 接入规则

StepFun 是 DeepFrames 的 provider，不是独立于 DeepBase 的旁路客户端。

- Chat 能力优先通过 `DeepBase.LLM` provider adapter 接入。
- TTS / ASR 能力通过 `DeepBase.Speech` provider adapter 接入。
- 图像能力由 DeepFrames 的 StepFun image adapter 封装，但配置、密钥、日志和重试仍接入 DeepBase。
- API Key 使用 `DeepBase.Security.SaveSecret/LoadSecret` 保存，不写入 `.env`、JSON、INI、日志或 DB2 业务表。
- 网络调用不得阻塞 VCL UI 线程，使用后台任务或 worker queue。
## 模型清单

### 推理模型

| 模型 ID | 用途 | 备注 |
|---|---|---|
| `stepfun-flash-3.5` | 快速推理 | 默认文字模型，用于 Splitter/Worker/Assembler/Style Keeper |
| `deepseek-v4-pro` | 强推理/复核 | 用于 QA、复杂章节或人工指定的高质量复核 |

> LLM 路由策略不属于 DeepFrames 当前设计范围。生产前由用户在配置中明确指定各 Agent 使用 `stepfun-flash-3.5` 或 `deepseek-v4-pro`，DeepFrames 不内置自动路由决策。

### 音频模型

| 模型 ID | 用途 | 备注 |
|---|---|---|
| `stepaudio-2.5-tts` | 文本转语音 | 多角色、情感控制，已测试通过 |
| `stepaudio-2.5-asr` | 语音转文本 | 流式 SSE，4B MTP 架构 |
| `stepaudio-2.5-realtime` | 实时语音 | WebSocket |
| `stepaudio-2.5-chat` | 语音对话 | 文本入文本出 |

### 图像模型

| 模型 ID | 用途 | 备注 |
|---|---|---|
| `step-image-edit-2` | 文生图 + 图像编辑 | 1-2 秒/任务 |

## 接口详情

### Chat Completion

```
POST /chat/completions
```

请求体：
```json
{
  "model": "stepfun-flash-3.5",
  "messages": [
    {"role": "system", "content": "..."},
    {"role": "user", "content": "..."}
  ],
  "stream": false
}
```

支持流式输出（`stream: true`），支持 reasoning_content 返回推理过程。

### TTS 语音合成

```
POST /audio/speech
```

请求体：
```json
{
  "model": "stepaudio-2.5-tts",
  "input": "要合成的文本内容",
  "voice": "cixingnansheng",
  "instruction": "语气温柔，语速偏慢",
  "response_format": "wav"
}
```

参数说明：
- `voice`: 预置音色 ID，支持自定义克隆音色
- `instruction`: 情感/语速/语气控制指令
- `response_format`: mp3 / wav / opus / pcm

内置音色列表（常用）：
- `cixingnansheng` — 慈性男声
- 更多音色见官方文档

流式 TTS：
```
WSS wss://api.stepfun.com/step_plan/v1/realtime/audio
```

### ASR 语音识别

```
POST /audio/asr/sse
```

支持流式返回。在 DeepFrames 中用于两个场景：
1. 校验 TTS 音频内容与原文一致性
2. 获取逐字时间戳（word-level timestamp），供视频卡拉 OK 字幕同步使用

### 图像生成

```
POST /images/generations
```

用于生成视频背景图、封面图、场景插画。

### 图像编辑

```
POST /images/edits
```

基于已有图像进行编辑修改。

### 声音克隆

```
POST /audio/voices
```

上传声音样本，创建自定义音色。

### 声音预览

```
POST /audio/voices/preview
```

预览音色效果。

## 在 DeepFrames 中的使用场景

| 场景 | 接口 | 说明 |
|---|---|---|
| 小说文本分析 | Chat | 章节切分、角色识别、场景标注 |
| Agent 推理 | Chat | 各 Agent 节点的推理决策（Splitter/Worker/QA/Style Keeper） |
| QA 审核 | Chat (`deepseek-v4-pro` 或人工指定模型) | 默认使用强模型做质量把关，最终模型选择生产前确定 |
| 角色配音 | TTS | 多角色多音色配音，结构化情感控制 |
| 字幕同步 | ASR | 校验音频内容 + 获取逐字时间戳 |
| 场景插画 | Image Gen | 视频背景、场景画面（多比例版本） |
| 封面制作 | Image Edit | 各平台封面（不同尺寸） |
| 元数据生成 | Chat | 平台差异化标题/标签/描述 |

## 注意事项

- 短中文文本可能触发内容审查（HTTP 451），确保输入为自然完整句子
- TTS 输出为二进制音频流，直接写入文件，非 JSON。生产中间格式优先 WAV/PCM，平台候选包阶段再转 MP3/AAC
- 图像生成 1-2 秒/任务，适合批量调用
- WebSocket 接口用于实时场景，批量生成用 REST 即可
