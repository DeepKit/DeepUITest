# 快速上手

本文从用户操作视角描述 DeepFrames 的核心使用流程，帮助新用户在 10 分钟内理解"坐下来生产一条视频"的完整过程。

## 首次生产流程（端到端）

```
导入原文 → 选择预设 → Agent 分析 → 人工审查 → 音频生成 → 视频合成 → 导出候选包
```

### 第 1 步：导入原文

1. 新建项目，选择内容类型（默认：`longform_zh_article` 中文长文；网文使用独立类型 `webnovel_zh`）
2. 导入原文（文件路径或粘贴文本）
3. 系统自动创建 `source_document`，进入 `done` 状态

### 第 2 步：选择预设与配置

1. 选择风格预设（如 `xuanhuan` 玄幻仙侠、`dushi` 都市现代）
2. 选择目标平台（喜马拉雅 / B站 / 抖音 / 小红书）
3. 确认目标时长（默认 15 分钟，即 900 秒）
4. 确认表达模式：
   - **准确模式**（默认）：忠实原文，适合有声书
   - **表达增强模式**：允许轻度口语化和渲染，适合短视频预告

> 以上配置均有默认值，首次使用可直接跳过，用默认配置生产。

### 第 3 步：Agent 分析（自动，约 5-15 分钟）

点击"开始生产"后，系统自动运行 Agent 链路：

1. **Splitter**：将章节切分为镜头单元（4-6 秒/镜头）
2. **Worker**：为每个镜头生成画面描述、音频指令（5-8 路并行）
3. **Assembler**：补全时间轴和格式校验
4. **QA**：质量审核（默认使用强模型）
5. **Style Keeper**：跨镜头风格一致性检查

**期间用户可以**：
- 📊 查看实时进度（当前阶段、已完成/总数）
- 👁 预览已完成镜头的结构化输出
- ⏹ 任意时刻取消（已完成的镜头保留为断点）

### 第 4 步：人工审查（Gate 2）

Agent 完成后进入 **Gate 2 审核**：

| QA 结果 | 用户操作 |
|---------|---------|
| 🟢 Pass | 自动通过，无需操作 |
| 🟡 Warn | 展示警告项，用户选择"接受"或"重做" |
| 🔴 Fail | 标记问题镜头，展示给用户，用户确认后回流重做 |

降级镜头（`degraded: true`）在结果区单独标注，用户可以选择接受降级或重新生产。

### 第 5 步：音频生成（自动，约 5-10 分钟）

通过 Gate 2 后，音频流水线自动启动：

1. 音色映射（角色 → 声音）
2. 批量 TTS（5 路并行）
3. ASR 校验 + 逐字时间戳
4. 音频拼接 + 响度标准化

音频和视频是**两条独立流水线**，可以并行运行。用户无需等音频完成即可开始视频预览。

### 第 6 步：视频合成（自动）

1. 按镜头生成背景图（文生图 / 图生图）
2. 全局时间轴量化（帧级精确对齐）
3. 渲染模式可选：
   - `visual-preview`：图片序列预览（无音频）
   - `timed-preview`：估时预览（按预估时长）
   - `final-with-audio`：最终合成（需音频完成）

### 第 7 步：Gate 3 审核 + 导出

1. **Gate 3a**（音频质量）：响度合规、时长一致性
2. **Gate 3b**（视频质量）：分辨率、帧率、编码合规
3. 通过后生成候选包，按平台规格导出

## 常用操作

### 断点续跑

上次生产中断后，重新打开项目点击"继续生产"即可。系统自动跳过已完成的镜头，从中断处继续。

### A/B 版本对比

同一内容可以创建两个版本（如保守准确 vs 大胆演绎），在结果区并排对比差异。

### 返工单个镜头

在 Gate 2 审查界面，选中问题镜头，点击"重做该镜头"。系统只重新处理选中的镜头，不影响其他已完成的部分。

### 重新生成音频

音频流水线可以独立重新运行，不需要重新走 Agent 链路。修改音色映射后点击"重新生成音频"即可。

## 核心概念速查

| 概念 | 含义 |
|------|------|
| 镜头 (shot) | 最小生产单元，通常 4-6 秒 |
| 镜头组 (group) | 3-5 个语义相近的镜头，共享视觉风格 |
| 候选包 (candidate package) | 按平台规格导出的最终产物 |
| Gate | 质量检查点（Gate 1/2/3a/3b） |
| 降级 (degraded) | 质量未达标但保持时间轴完整的镜头 |
| 风格锚点 (style anchor) | 章节级视觉风格定义，保证画面一致性 |
