## 2. 当前冻结判断

```text
1. 产品名：深测 DeepUITest。
2. 第一阶段定位：自用基础设施 + OCGS 样板工程。
3. 对外表达：AI 辅助的 Windows 桌面软件行为回归测试系统。
4. 第一阶段范围：Windows 桌面程序，优先 Delphi VCL，兼顾 FMX on Windows。
5. 第一被测对象：DeepLaunch。
6. 第一条样板链：DeepLaunch 已配置启动链，F1 + X -> 指定程序启动。
7. 第一版策略：先跑通人工配置测试链，再接 AI 配置生成。
8. 核心闭环：行为链配置 -> Runner 回放 -> 状态断言 -> 红绿灯 -> 失败诊断 -> BugRecord。
9. 数据部署：DeepBase DB1 + DB2 本地优先；DB3 走产品业务 API；DB4 统一走 DeepBase Commerce/Auth 框架，桌面端不直连公网 PG 或支付认证库。
```

## 4. 当前最重要的工程入口

第一阶段不要从 AI 配置生成器开始，也不要从完整 Designer 开始。

第一工程入口是：

```text
手工配置一条 TestCase
  -> Runner 读取配置
  -> 定位或启动 DeepLaunch
  -> 发送 F1 + X
  -> 验证 DeepUITestProbe.exe 启动
  -> 写 RunnerResult / RunnerStepResult
  -> 生成 LampEvaluation
  -> 失败时生成 BugRecord / BugDiagnosis
```

这个闭环跑通后，才继续补 Designer、VCL/FMX 代码读取和 AI 配置生成。
