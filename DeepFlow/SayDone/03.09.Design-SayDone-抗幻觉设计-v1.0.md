## 8. 核心原则

```
1. 结构先行：AI只能在预定义结构内填值，不能创造结�?
2. 枚举约束：能用枚举的地方不用自由文本
3. 引用验证：AI提到的任何东西都必须真实存在
4. 多层过滤：Schema �?引用 �?逻辑 �?语义，层层把�?
5. 用户在环：关键决策让用户确认，错误易于发现和回滚
6. 持续学习：从幻觉中学习，不断加强约束
```

**SayDone的优�?*：我们不是让AI写文章，而是让AI填表格。表格的列是固定的，值是受限的，幻觉的空间被大大压缩�?
