# SayDone (述成)

> **述说即成** 用自然语言构建结构化数据
>
> Say it, Done.

---

## 项目定位

SayDone 是 DevDirector 的核心子项目，实现自然语言到结构化数据的转换引擎。

**核心公式：**
```
结构化抽取 = 领域识别 + 模板激活 + 增量修改 + 超模板AI补充
```

**愿景**：让每个人都能把想法变成软件

## 核心概念

### 三层架构

```
┌─────────────────────────────────────────┐
│  用户：说人话、看结果、挑毛病          │
└─────────────────────────────────────────┘
                     ↓
┌─────────────────────────────────────────┐
│ 对话转化流程：意图解析→领域识别→模板匹配→渲染→输出 │
└─────────────────────────────────────────┘
                     │
┌─────────────────────────────────────────┐
│ 数据转化流程：结构化数据（用户不可见）         │
└─────────────────────────────────────────┘
```

### 9个后台角色

| 角色 | 职责 |
|------|------|
| 总导演 | 全局调度、约束执行 |
| 监制 | 流程监控、质量把控 |
| AI代理 | 意图理解、内容生成 |
| 共情引擎 | 情绪感知、表达优化 |
| 记忆引擎 | 上下文管理、历史追踪 |
| 守卫引擎 | 安全检查、格式校准 |
| 自检引擎 | AI自我审查 |
| Diff分析引擎 | 变更计算、冲突检测 |
| 回退日志 | 版本管理、一键回退 |

### 交互四要诀

1. **先猜后确认** 直接给用户看结果，比让用户描述内容好100倍
2. **即时反馈** 在0.5秒内必须有响应？
3. **渐进显影** 要先出轮廓，再填细节
4. **温柔纠错** 即理解错了提供选项，不让用户尴尬

## UniFlow 的关键

- SayDone 在实现上遵循 `../03.01.Design-uniFlow-CoreModelAndPrinciples-1.0.md` 中定义的 UniFlow 模型。
- 所有「自然语言 →结构化数据」的处理过程，都将以 `UniFlowEvent` 的形式记录到统一的流程历史中。
- Loop A / Loop B 中与结构化转换相关的步骤，只定义业务语义，不再维护独立的流程与历史模型。
