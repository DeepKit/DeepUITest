### 8.2 连接器接口规范

```typescript
interface CommercialConnector extends Connector {
  // 基础信息
  id: string;
  name: string;
  description: string;
  icon: string;
  
  // 商业属性
  pricing: {
    model: 'free' | 'subscription' | 'per-use' | 'tiered';
    price?: number;
    unit?: 'month' | 'use' | 'seat';
    freeQuota?: number;
  };
  
  // 权限要求
  requiredAuth?: {
    type: 'oauth' | 'apikey' | 'token';
    provider: string;
  };
  
  // 执行
  execute(data: StructuredOutput, auth: AuthContext): Promise<ConnectorResult>;
  
  // 预览（不消耗配额）
  preview?(data: StructuredOutput): Promise<PreviewResult>;
}
```

### 16.1 方案对比

| 维度 | 作为DevDirector子项 | 新建独立项目 |
|------|---------------------|-------------|
| 定位 | DevDirector的核心功能之一 | 独立的通用平台 |
| 用户 | 开发者（DevDirector用户） | 所有需要结构化数据的人 |
| 技术栈 | Delphi/FMX | 可自由选择 |
| 天花板 | 受限于DevDirector市场 | 理论上无限大 |

### 16.2 建议路径：先生孩子，长大了再分家

```

· 验证"需求→结构化数据"方法可行
· 积累第一批用户和反馈
· 代码架构保持可抽取

阶段2：服务化（1-6个月内）
────────────────────────
· 核心引擎抽象为独立服务/API
```
