## 1. 错误码规范

### 1.1 命名规则

```
{CATEGORY}_{SUB_CATEGORY}_{DETAIL}

示例：ENGINE_ROLE_NOT_FOUND
      GUARD_PERMISSION_DENIED
```

### 1.2 分类前缀

| 前缀 | 来源/职责 | 数字范围 | 说明 |
|------|-----------|----------|------|
| `ENGINE_` | 引擎/基础设施 | 1000-1999 | 系统级错误 |
| `GUARD_` | 守卫/校验 | 2000-2999 | 权限与校验错误 |
| `AI_` | 智囊/AI 推理 | 3000-3999 | LLM 相关错误 |
| `SKILL_` | 执行器/Skill | 4000-4999 | Skill 执行错误 |
| `EXTERNAL_` | 通信网关/外部服务 | 5000-5999 | 外部调用错误 |
| `WORKFLOW_` | 调度器/Workflow | 6000-6999 | 流程执行错误 |
| `BIZ_` | 业务逻辑 | 7000-7999 | 业务规则错误 |
| `DATA_` | 数据层 | 8000-8999 | 数据访问错误 |
| `MCP_` | MCP 协议 | 9000-9999 | MCP 集成错误 |

### 1.3 严重程度

| 等级 | 标记 | 描述 | HTTP 状态码 |
|------|------|------|-------------|
| L1 | 🔴 Fatal | 系统级故障 | 500 |
| L2 | 🟠 Error | 请求级故障 | 4xx/5xx |
| L3 | 🟡 Warning | 降级运行 | 200 (带警告) |
| L4 | 🟢 Info | 业务拒绝 | 400/403 |

## 12. 错误码索引

### 12.1 按可重试性分类

**可重试错误**
- `ENGINE_ROLE_UNAVAILABLE`, `ENGINE_MESSAGE_TIMEOUT`, `ENGINE_QUEUE_FULL`
- `GUARD_RATE_LIMITED`, `GUARD_TOKEN_EXPIRED`, `GUARD_CONCURRENT_LIMIT_REACHED`
- `AI_TIMEOUT`, `AI_RATE_LIMITED`, `AI_MODEL_UNAVAILABLE`, `AI_PARSE_FAILED`, `AI_EMPTY_RESPONSE`, `AI_MALFORMED_OUTPUT`
- `SKILL_TIMEOUT`, `SKILL_DEPENDENCY_FAILED`, `SKILL_PYTHON_SERVICE_UNAVAILABLE`, `SKILL_PYTHON_BRIDGE_ERROR`
- `EXTERNAL_SERVICE_UNAVAILABLE`, `EXTERNAL_TIMEOUT`, `EXTERNAL_RATE_LIMITED`, `EXTERNAL_SERVER_ERROR`
- `WORKFLOW_TIMEOUT`
- `DATA_CONNECTION_FAILED`, `DATA_QUERY_FAILED`, `DATA_DEADLOCK`
- `MCP_TOOL_EXECUTION_FAILED`, `MCP_TOOL_TIMEOUT`

**不可重试错误**
- 所有`*_NOT_FOUND` 错误
- 所有`*_PERMISSION_DENIED` 错误
- 所有`*_INVALID*` 错误
- `GUARD_SCHEMA_VIOLATION`, `GUARD_BUDGET_EXCEEDED`
- `AI_CONTEXT_TOO_LONG`, `AI_SAFETY_BLOCKED`

### 12.2 与HTTP 状态码映射

| HTTP | 错误码范围 |
|------|-----------|
| 400 | `GUARD_SCHEMA_*`, `BIZ_INVALID_*`, `*_INVALID_PARAMS` |
| 401 | `GUARD_AUTHENTICATION_FAILED`, `EXTERNAL_AUTH_FAILED` |
| 403 | `GUARD_PERMISSION_DENIED`, `GUARD_DATA_LEVEL_EXCEEDED` |
| 404 | `*_NOT_FOUND` |
| 408 | `*_TIMEOUT` |
| 429 | `*_RATE_LIMITED`, `GUARD_BUDGET_EXCEEDED` |
| 500 | `ENGINE_*_FAILED`, `DATA_*` |
| 502 | `EXTERNAL_*` |
| 503 | `*_UNAVAILABLE` |

## 13. 维护指南

### 13.1 新增错误码流程

1. 确定错误分类（ENGINE/GUARD/AI/SKILL/EXTERNAL/WORKFLOW/BIZ/DATA/MCP）
2. 在对应数字范围内选择编号
3. 定义错误码名称（遵循 `{CATEGORY}_{SUB}_{DETAIL}` 格式。
4. 填写等级、可重试性、描述、建议处置。
5. 更新本文档。
6. 在代码中注册错误码。
