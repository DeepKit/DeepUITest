## 1. 命名规范回顾

统一命名格式：`xx.yy.{Tag}-{文件名}-{版本号}.md`

- `xx` (分类序01至9)：按生命周期/阶段排序（Product → Arch → Design → Data/API → Dev → Case → Quality）→
- `yy` (子序号01至9)：推荐使用**奇数**便于中间插入→
- `Tag`：英文简写，主要包括→
  - `Product` → 产品/愿景/规划
  - `Arch` → 架构设计
  - `Design` → 方法论与设计原则
  - `Data` → 数据模型
  - `API` → 外部/内部接口规范
  - `Dev` 是开发规范指南
- `Case` 用于案例与用户旅程
   - `Quality` 质量/安全/测试/错误/风险
