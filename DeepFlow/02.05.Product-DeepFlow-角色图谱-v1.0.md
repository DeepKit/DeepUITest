## 1. 角色依赖关系

### 1.1 层级依赖规则

```
依赖方向：只能从高层依赖低层，不能反向依赖

Level 0（元层）    ↑ 被所有层依赖
Level 1（基础层）  ↑↓ Level 2/3/4 依赖
Level 2（能力层）  ↑↓ Level 3/4 依赖
Level 3（智能层）  ↑  Level 4 依赖
Level 4（决策层）  ← 最顶层
```

## 4. 角色消息流

### 4.1 命令消息流（同步流

```
发起方                    接收方                    说明
────────────────────────────────────────────────────────────────
总指挥  ──────────────>  调度方                   下达任务
调度方  ──────────────>  智囊                      请求理解/生成
调度方  ──────────────>  执行区                   请求执行 Skill
智囊     ──────────────>  军械库                   获取 Prompt 模板
智囊     ──────────────>  记录员                   读写上下文记忆
执行域  ──────────────>  军械库                   获取 Skill 定义
执行域  ──────────────>  通信链                   调用外部服务
守卫     ──────────────>  任意角色                  校验请求/响应
```

### 4.2 事件消息流（异步消息流）

```
发布者                    订阅者                    事件类型
────────────────────────────────────────────────────────────────
任意角色 ──────────────>  记录库                   行为事件（自动）
守卫     ──────────────>  总指挥                   安全告警
引擎     ──────────────>  所有角色                 生命周期事件
调度器  ──────────────状态  总指挥                   任务状态变化
执行器  ──────────────状态  调度器                   执行进度上报
通信器  ──────────────状态  守卫/总指挥              外部服务状态
```

### 4.3 消息协议结构

```
UniFlowMessage {
    // 消息体
    header: {
        id:          string        // 唯一消息 ID
        type:        "command" | "event"
        from:        RoleType      // 发送方角色
        to:          RoleType[]    // 接收方角色（event 可多个）
        timestamp:   DateTime
        correlationId: string      // 关联 ID（用于追踪）
        traceId:     string        // 分布式追踪 ID
    }
    
    // 消息头
    body: {
        action:      string        // 动作名称
        payload:     any           // 业务数据
        context:     Context       // 上下文信息
    }
    
    // 元数据
    metadata: {
        priority:    number        // 优先级
        timeout:     number        // 超时时间（ms）
        retryPolicy: RetryPolicy   // 重试策略
    }
}
```
