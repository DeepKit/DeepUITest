## 1. 概述

### 1.1 DeepFlow 是什么？

DeepFlow = **智能应用的操作系统**

- 提供 11 个标准化角色的运行时
- 提供 Workflow 流程引擎
- 提供 Skill 扩展机制（Delphi + Python）
- 提供安全与信任边界
- 提供多层记忆体系

### 1.2 第一个验证场景

**洞见·思维显影室（DeepInsight）** 将作为DeepFlow MVP的首个验证应用

## 5. 开发约定指导

### 5.1 代码规范

遵循 `D:\_Progs\05docs\delphi程序开发约定指南.md`。

- 四层隔离：View / Ctrl / Model / uDM
- 变量前缀：F（字段）、L（局部）、A（参数）
- 接口优先：角色通过接口通信
- UTF-8 + BOM 编码

### 5.2 消息驱动

角色间通信使用 `DeepBase.EventBus`。

```pascal
// 发布消息
EventBus.Publish<TCommanderTaskMsg>(TaskMsg);

// 订阅消息
EventBus.Subscribe<TCommanderTaskMsg>(
  procedure(const Msg: TCommanderTaskMsg)
  begin
    HandleTask(Msg);
  end);
```

### 5.3 Skill 开发

**Delphi Skill**：
```pascal
type
  TMySkill = class(TInterfacedObject, ISkill)
    function Execute(const Input: TSkillInput): TSkillOutput;
  end;
```

**Python Skill**：
```python
@app.post("/skills/my_skill/execute")
async def my_skill(req: SkillRequest):
    # 实现逻辑
    return {"success": True, "output": result}
```

### 5.4 测试策略

| 层级 | 测试方式 |
|------|----------|
| 单元测试 | DUnitX |
| 角色测试 | Mock + EventBus |
| 集成测试 | 完整 Workflow |
| Python Skill | pytest |
