# DeepFlow 开发者快速上手指南

| 版本 | 日期 | 作者 | 变更说明 |
|------|------|------|----------|
| v1.0 | 2024-12-04 | 产品经理 | 初稿，定稿于 5/15/30 分钟上手路径 |

## 前言

本指南帮助外部开发者快速集成 DeepFlow。按照以下三步路径，您可以：
- **5 分钟**：调通第一个 API
- **15 分钟**：执行一个完整 Workflow
- **30 分钟**：接收异步回调并处理结果

---

## 1. 5 分钟 - Hello World

### 1.1 前置条件

- DeepFlow 服务已启动（默认 http://localhost:8080/）
- 获取 API Key（联系管理员或在控制台生成）
- 准备 HTTP 客户端（curl、Postman 或代码）

### 1.2 测试连接

```bash
# 检查服务状态
curl http://localhost:8080/health

# 期望响应
{
  "status": "healthy",
  "version": "1.0.0",
  "timestamp": 1733323172
}
```

### 1.3 执行第一个 Skill

```bash
# 调用 echo Skill（内置，用于测试吧）
curl -X POST http://localhost:8080/api/v1/skill/execute \
  -H "Content-Type: application/json" \
  -H "X-API-Key: your-api-key" \
  -d '{
    "skill_name": "builtin.echo",
    "input": {
      "message": "Hello DeepFlow!"
    }
  }'

# 期望响应
{
  "success": true,
  "data": {
    "output": "Hello DeepFlow!",
    "timestamp": "2024-12-04T10:30:45Z"
  },
  "request_id": "req-xxx-xxx"
}
```

### 1.4 常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| 401 Unauthorized | API Key 无效或缺失 | 检查 X-API-Key header |
| 404 Not Found | Skill 不存在 | 使用 `builtin.echo` 测试 |
| 503 Service Unavailable | 服务未就绪 | 等待几秒后重试 |

**恭喜** 您已成功调通第一个 DeepFlow API。

```bash

  -H "Content-Type: application/json" \
```

### 2.3 异步执行（推荐用于长时间任务）

```bash
# 步骤 1：提交异步任务
curl -X POST http://localhost:8080/api/v1/workflow/execute \
  -H "Content-Type: application/json" \
  -H "X-API-Key: your-api-key" \
  -d '{
    "workflow_id": "DeepInsight-flow",
    "input": {
      "topic": "如何提高团队协作效率"
    },
    "options": {
      "sync": false
    }
  }'

# 响应（立即返回，任务在后台执行）
{
  "success": true,
  "execution_id": "exec-abc-123",
  "status": "running",
  "message": "Workflow submitted, use execution_id to query status"
}

# 步骤 2：查询执行状态
curl -X GET http://localhost:8080/api/v1/workflow/status/exec-abc-123 \
  -H "X-API-Key: your-api-key"

# 响应
{
  "execution_id": "exec-abc-123",
  "workflow_id": "DeepInsight-flow",
  "status": "running",
```

## 3. 30 分钟 - Webhook 回调

### 3.1 配置 Webhook

在执行 Workflow 时指定回调地址。

```bash
curl -X POST http://localhost:8080/api/v1/workflow/execute \
  -H "Content-Type: application/json" \
  -H "X-API-Key: your-api-key" \
  -d '{
    "workflow_id": "DeepInsight-flow",
    "input": {
      "topic": "数字化转型策略"
    },
    "webhook": {
      "url": "https://your-server.com/webhook/uniflow",
      "events": ["completed", "failed", "progress"],
      "headers": {
        "Authorization": "Bearer your-webhook-secret"
      }
    }
  }'
```

### 3.2 Webhook 事件类型

| 事件 | 触发时机 | 说明 |
|------|----------|------|
| `workflow.started` | Workflow 开始执行 | 可用于更新 UI 状态 |
| `workflow.progress` | 步骤完成/状态变化 | 实时进度通知 |
| `workflow.completed` | Workflow 成功完成 | 包含完整结果 |
| `workflow.failed` | Workflow 执行失败 | 包含错误详情 |
| `workflow.cancelled` | Workflow 被取消 | 用户或系统取消 |

### 3.3 Webhook 请求格式

DeepFlow 将向您的 Webhook URL 发送 POST 请求。

```json
{
  "event": "workflow.completed",
  "timestamp": "2024-12-04T10:35:00Z",
  "data": {
    "execution_id": "exec-abc-123",
    "workflow_id": "DeepInsight-flow",
    "status": "completed",
    "result": {
      "DeepInsights": [
        {
          "title": "洞见1",
          "content": "..."
        }
      ],
      "summary": "..."
    },
    "metadata": {
      "duration_ms": 45000,
      "tokens_used": 12500
    }
  },
  "signature": "sha256=xxxx"  // 用于验证请求来源
}
```

### 3.4 验证 Webhook 签名

为确保安全，您应验证 Webhook 请求的签名：

```python
import hmac
import hashlib

def verify_webhook(payload: bytes, signature: str, secret: str) -> bool:
    """验证 Webhook 签名"""
    expected = hmac.new(
        secret.encode(),
        payload,
        hashlib.sha256
    ).hexdigest()
    return hmac.compare_digest(f"sha256={expected}", signature)

# Flask 示例
@app.route('/webhook/uniflow', methods=['POST'])
def handle_webhook():
    signature = request.headers.get('X-UniFlow-Signature')
    if not verify_webhook(request.data, signature, WEBHOOK_SECRET):
        return jsonify({'error': 'Invalid signature'}), 401
    
    event = request.json
    
    if event['event'] == 'workflow.completed':
        process_result(event['data'])
    elif event['event'] == 'workflow.failed':
        handle_error(event['data'])
    
    return jsonify({'received': True})
```

### 3.5 Webhook 重试机制

DeepFlow 会自动重试失败的 Webhook 请求。

| 重试次数 | 等待时间 | 说明 |
|----------|----------|------|
| 1 | 立即 | 首次请求 |
| 2 | 10 秒 | 第一次重试 |
| 3 | 60 秒 | 第二次重试 |
| 4 | 5 分钟 | 第三次重试 |
| 5 | 30 分钟 | 最后一次重试 |

**重试条件**：
- HTTP 状态码 5xx（服务器错误）
- 连接超时（默认 10 秒）
- 网络错误

**不重试**：
- HTTP 状态码 2xx（成功）
- HTTP 状态码 4xx（客户端错误，除 429）

## 代码示例

### Python SDK 使用

```python
from uniflow import UniFlowClient

# 初始化客户端
client = UniFlowClient(
    base_url="http://localhost:8080",
    api_key="your-api-key"
)

# 同步执行 Workflow
result = client.workflow.execute(
    workflow_id="simple-qa",
    input={"question": "什么是 DeepFlow？"},
    sync=True
)
print(result.answer)

# 异步执行 + 轮询
execution = client.workflow.execute_async(
    workflow_id="DeepInsight-flow",
    input={"topic": "AI 发展趋势"}
)

# 等待完成
result = execution.wait(timeout=300)
print(result.DeepInsights)

# 或者使用回调
execution.on_complete(lambda r: print(r.DeepInsights))
execution.on_progress(lambda p: print(f"Progress: {p.percentage}%"))
```

### JavaScript/TypeScript 示例

```typescript
import { UniFlowClient } from '@uniflow/sdk';

const client = new UniFlowClient({
  baseUrl: 'http://localhost:8080',
  apiKey: 'your-api-key'
});

// 执行 Workflow
async function runWorkflow() {
  const result = await client.workflow.execute({
    workflowId: 'simple-qa',
    input: { question: '什么是 DeepFlow？' },
    sync: true
  });
  
  console.log(result.answer);
}

// 使用 SSE 接收实时进度
const stream = client.workflow.executeStream({
  workflowId: 'DeepInsight-flow',
  input: { topic: 'AI 发展趋势' }
});

stream.on('progress', (data) => {
  console.log(`Step ${data.currentStep}: ${data.percentage}%`);
});

stream.on('complete', (result) => {
  console.log('Done:', result);
});
```

## 错误处理

### 错误响应格式

```json
{
  "success": false,
  "error": {
    "code": "WORKFLOW_NOT_FOUND",
    "message": "Workflow 'unknown-flow' not found",
    "details": {
      "workflow_id": "unknown-flow",
      "available_workflows": ["simple-qa", "DeepInsight-flow"]
    }
  },
  "request_id": "req-xxx-xxx"
}
```

### 常见错误：

| 错误代码 | HTTP 状态 | 说明 | 处理建议 |
|--------|-----------|------|----------|
| `AUTH_FAILED` | 401 | 认证失败 | 检查API Key |
| `PERMISSION_DENIED` | 403 | 无权限 | 联系管理员 |
| `WORKFLOW_NOT_FOUND` | 404 | Workflow 不存在 | 检查workflow_id |
| `INVALID_INPUT` | 400 | 输入参数无效 | 检查input 格式 |
| `RATE_LIMITED` | 429 | 请求过于频繁 | 降低请求频率 |
| `EXECUTION_TIMEOUT` | 504 | 执行超时 | 使用异步模式 |
| `SERVICE_DEGRADED` | 503 | 服务降级 | 稍后重试 |

### 错误处理最佳实践

```python
from uniflow import UniFlowClient, UniFlowError, RateLimitError

client = UniFlowClient(...)

try:
    result = client.workflow.execute(...)
except RateLimitError as e:
    # 等待后重试
    time.sleep(e.retry_after)
    result = client.workflow.execute(...)
except UniFlowError as e:
    # 记录错误
    logger.error(f"DeepFlow error: {e.code} - {e.message}")
    # 根据错误码处理
    if e.code == "SERVICE_DEGRADED":
        # 使用备用方案
        pass
```
