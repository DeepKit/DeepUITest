## 1. DeepFlow 是什么？仅需 5 分钟搞定？

DeepFlow 是一款**AI Agent 协作引擎**，采用"军事指挥"隐喻设计，将 AI 能力分解为 11 个专职角色协同工作。

### 1.1 一句话理解

```
用户请求 → 11个角色协作完成 → 智能响应
```

### 1.2 核心价值

- **AI 能力复用**：一次接入LLM，所有业务复用。
- **安全可控**：所有AI 输入输出都经过审核。
- **可观测***：每个决策过程都可追溯。

### 1.3 11 角色速览

```
┌─────────────────────────────────────────────────────────────┐
│                     DeepFlow 角色图谱                        │
├─────────────────────────────────────────────────────────────┤
? 🎯 指挥官?                                                  │?
?    Commander(总指挥) │?Dispatcher(调度员) │?Executor(执行员) │?
?                                                             │?
? 🧠 智能助手?                                                  │?
?    Advisor(智囊) - AI 推理    Memory(记忆) - 上下文管理器?     │?
?                                                             │?
? 🛡️?安全策略?                                                  │?
?    Guard(守卫) - 输入输出审核                                │?
?                                                             │?
? 🔧 支撑服务?                                                  │?
?    Quartermaster(军需官) - Skill/Prompt 管理                │?
?    SignalOfficer(通信兵) - 外部 API 调用                    │?
•    Logistics(后勤) - 配置和资源?                            ?
•    Chronicler(记录员? - 日志和审计?                         ?
•                                                             ?
• ⚙️ 系统功能?                                                  ?
•    Engine(引擎) - 角色生命周期    Inspector(督察) - 调试     ?
└─────────────────────────────────────────────────────────────?
```

### 1.4 典型请求流程

```
用户: "帮我分析这个决策"
      处理
[Commander] 接收请求，权限检查
      配置环境
[Dispatcher] 创建 Workflow，安排任务
      执行
[Advisor] 调用 LLM 理解意图
      分析结果
[Executor] 执行 decision_coach Skill
      已执行?
[Guard] 审核输出内容
      已审核?
返回: 多角度分析结果?
```

## 3. Hello World Skill（约 2 分钟）完成?

### 3.1 创建 Delphi Skill

```pascal
// skills/SkillHello.pas
unit SkillHello;

interface

uses
  UniFlow.Skill.Base, System.JSON;

type
  TSkillHello = class(TBaseSkill)
  public
    class function GetId: string; override;
    class function GetDescription: string; override;
    function Execute(AInput: TJSONObject; AContext: TJSONObject): TSkillResult; override;
  end;

implementation

class function TSkillHello.GetId: string;
begin
  Result := 'hello';
end;

class function TSkillHello.GetDescription: string;
begin
  Result := '返回问候语';
end;

function TSkillHello.Execute(AInput: TJSONObject; AContext: TJSONObject): TSkillResult;
var
  LName: string;
begin
  // 获取输入参数
  LName := AInput.GetValue<string>('name', 'World');
  
  // 构建结果
  Result := TSkillResult.Success(
    TJSONObject.Create.AddPair('greeting', 'Hello, ' + LName + '!')
  );
end;

initialization
  // 注册 Skill
  TSkillRegistry.Register(TSkillHello);

end.
```

### 3.2 创建 Python Skill

```python
# skills/skill_hello_ai.py
from uniflow.skill import Skill, skill_result

class HelloAISkill(Skill):
    """使用 AI 生成个性化问候"""
    
    skill_id = "hello_ai"
    description = "AI 生成个性化问候语"
    
    async def execute(self, input: dict, context: dict) -> dict:
        name = input.get("name", "朋友")
        style = input.get("style", "友好")
        
        # 调用 LLM
        prompt = f"用{style}的语气，给{name}写一句问候语，不超过0.1KB(约20字)字节"
        response = await self.advisor.generate(prompt)
        
        return skill_result(
            success=True,
            data={"greeting": response.content}
        )
```

### 3.3 测试 Skill

```pascal
// 单元测试
procedure TSkillHelloTest.TestBasicGreeting;
var
  LSkill: TSkillHello;
  LInput: TJSONObject;
  LResult: TSkillResult;
begin
  LSkill := TSkillHello.Create;
  try
    LInput := TJSONObject.Create;
    LInput.AddPair('name', '张三');
    
    LResult := LSkill.Execute(LInput, nil);
    
    CheckTrue(LResult.Success);
    CheckEquals('Hello, 张三!', LResult.Data.GetValue<string>('greeting'));
  finally
    LSkill.Free;
    LInput.Free;
  end;
end;
```

## 4. 调试速查表（2 分钟内）

### 4.1 日志查看

```bash
# 实时查看日志
tail -f logs/deepflow.log | grep "TRACE:你的traceId"

# 过滤特定角色
tail -f logs/deepflow.log | grep "[Commander]"
```

### 4.2 常见问题排查

| 症状 | 可能原因 | 解决方法 |
|------|----------|----------|
 | Python Skill 调用失败 | Python 服务未启动 | 检测`http://localhost:8765/health` |
 | LLM 响应超时 | API 网络问题 | 检查`config.llm.baseUrl` 配置 |
 | 权限被拒绝 | Guard 校验失败 | 查看日志中的 `GUARD_*` 错误信息 |
| Workflow 卡住 | HumanTask 等待中| 调用 `completeHumanTask` API |
| 角色不响应| 心跳超时 | Inspector 查看角色状态|

### 4.3 Inspector 调试命令

```pascal
// 获取角色状态
Inspector.GetRoleStatus('advisor');

// 查看消息队列
Inspector.GetPendingMessages('dispatcher');

// 注入 Mock
Inspector.InjectMock('signalOfficer', TMockSignalOfficer.Create);

// 设置断点
Inspector.SetBreakpoint('executor', 'beforeExecute');

// 追踪请求
Inspector.EnableTracing('trace-id-xxx');
```

### 4.4 错误码速查

| 错误码| 含义 | 处理建议 |
|--------|------|----------|
| `AI_TIMEOUT` | LLM 调用超时 | 增加 timeout 或重试|
| `AI_RATE_LIMIT` | API 限流 | 等待后重试|
| `GUARD_INJECTION_DETECTED` | Prompt 注入检测 | 检查用户输入 |
| `GUARD_HALLUCINATION` | 幻觉内容 | 重新生成或人工审核 |
| `SKILL_NOT_FOUND` | Skill 未注册 | 检查 Skill 注册代码 |
| `WORKFLOW_STEP_FAILED` | 步骤执行失败 | 查看 stepError 详情 |
| `PERMISSION_DENIED` | 权限不足 | 检查用户角色配置 |
| `BUDGET_EXCEEDED` | 预算超限 | 等待预算重置或调整限制 |

### 4.5 性能检查点

```
✓ 单次 Skill 执行 < 100ms（不依赖LLM调用）
✓ LLM 调用 P99 < 30s
✓ 角色间消息传输 < 5ms
✓ Workflow 状态持久化 < 50ms
```
