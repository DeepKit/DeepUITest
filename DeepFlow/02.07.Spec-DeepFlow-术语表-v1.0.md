# DeepFlow 术语表

> 统一定义 DeepFlow 文档中使用的专业术语和概念。
>
> **项目正名说明**：本项目原代号 UniFlow，已于 2026-08 正名。项目整体名 **DeepFlow**（文件名/目录/分支/schema URI 均用此名）。项目内部含两层架构：上层"角色协作引擎"名 **UpFlow**（原 UniFlow 大写），下层"事件溯源引擎"名 **deepFlow**（原 uniFlow 小写）。文档正文按上下文语义使用 DeepFlow/UpFlow/deepFlow。代码 unit 名本轮冻结仍为 `UniFlow.*`，待开会统一（详见 [ADR-002](./ADR/ADR-002-术语纠正与unit改名.md)）。文档中引用代码标识符（`UniFlowEvent`、`TUniFlowEngine`、`UniFlow.xxx.pas` 等）保留原样，与实际代码一致。

## 项目名与产品名（权威基准）

| 术语 | 英文 | 定义 |
|------|------|------|
| **DeepFlow** | DeepFlow | 本项目正名（原代号 UniFlow）。Delphi 族 AI 工作流运行时，让 AI 可控、可靠、可集成。项目整体名，文件名/目录/分支/schema URI 用此名。 |
| **UpFlow** | UpFlow | DeepFlow 内部上层"角色协作引擎"（原 UniFlow 大写）。11 角色协作、Workflow 编排、AI 能力复用、安全守卫。服务洞见/AI Agent。 |
| **deepFlow** | deepFlow | DeepFlow 内部下层"事件溯源引擎"（原 uniFlow 小写）。Flow/Event/Snapshot、历史回放、版本分叉。服务 SayDone/SoIs/DevDirector。 |
| **如是** | SoIs | 基于 DeepFlow 的 AI 决策辅助产品（中英并列：如是 SoIs）。 |
| **述成** | SayDone | 基于 DeepFlow 的任务执行产品（中英并列：述成 SayDone）。 |
| **洞见** | DeepInsight | 基于 DeepFlow 的 AI 决策辅助产品，将复杂决策过程可视化为电影式叙事结构。 |
| **DeepBase** | DeepBase | 底层基础框架，DeepFlow 的宿主环境。 |

> 组件名首次出现处一律"中文（英文）"并列，如"如是（SoIs）""述成（SayDone）"，后文可单用其一。

## 角色相关

| 术语 | 英文 | 定义 |
|------|------|------|
| **引擎** | Engine | 角色生命周期管理者，负责注册、启动、监控所有角色。 |
| **督察** | Inspector | 调试和监控角色，提供断点、Mock 注入、状态查看能力。 |
| **总指挥** | Commander | 请求入口角色，负责受理/拒绝请求、分配资源、返回最终响应。 |
| **调度官** | Dispatcher | 任务编排角色，管理 Workflow 定义和执行。 |
| **执行官** | Executor | 任务执行角色，调用 Skill 完成具体工作。 |
| **智囊** | Advisor | AI 推理角色，负责意图理解、内容生成、问题诊断。 |
| **守卫** | Guard | 安全审核角色，负责输入校验、权限检查、输出审核。 |
| **军械官** | Quartermaster | 资源管理角色，管理 Skill 和 Prompt 模板注册。 |
| **后勤** | Logistics | 基础设施角色，管理配置、缓存、临时资源。 |
| **记录官** | Chronicler | 日志审计角色，记录事件和提供多层记忆存储。 |
| **通信官** | SignalOfficer | 外部通信角色，负责调用外部 API（如 LLM）并处理熔断。 |
| **记忆** | Memory | 记忆管理角色，提供工作记忆、会话记忆、长期记忆。 |

## 执行模式

| 术语 | 英文 | 定义 |
|------|------|------|
| **硬执行** | Hard Execution | 必须精确完成的确定性操作，如数据库写入、API 调用。失败必须回滚或补偿。 |
| **软执行** | Soft Execution | 允许近似或降级的 AI 推理操作，如意图理解、内容生成。失败可降级处理。 |
| **快路径** | Fast Path | 跳过部分角色的优化执行路径，用于简单场景（如纯本地 Skill）。需满足特定条件。 |
| **慢路径** | Slow Path | 经过完整角色链的标准执行路径，用于复杂场景（含 AI 任务）。 |

## AI 相关

| 术语 | 英文 | 定义 |
|------|------|------|
| **置信度路由** | Confidence Routing | 根据 AI 输出的置信度级别决定后续处理方式（自动采用/人工确认/重新生成）。 |
| **置信度级别** | Confidence Level | AI 输出的可信程度分档：High（≥0.9）、Medium（0.7-0.9）、Low（<0.7）。 |
| **决策胶片** | Decision Film | 洞见（DeepInsight）产品的核心交付物，将复杂决策过程可视化为电影式叙事结构。 |
| **Prompt 注入** | Prompt Injection | 恶意用户通过输入特殊内容试图操控 AI 行为的攻击方式。 |
| **幻觉** | Hallucination | AI 生成的与事实不符的虚假内容。 |
| **Persona** | Persona | AI 助手的人格设定，定义其语气、风格、能力边界。 |

## Workflow 相关

| 术语 | 英文 | 定义 |
|------|------|------|
| **Workflow 定义** | Workflow Definition | 静态的任务编排模板，定义步骤、条件、分支。 |
| **Workflow 实例** | Workflow Instance | 运行时的 Workflow 执行状态，包含当前步骤、变量、历史。 |
| **步骤** | Step | Workflow 中的执行单元，类型包括 SkillTask、AITask、HumanTask、SubWorkflow。 |
| **人工任务** | HumanTask | 需要用户介入的步骤，Workflow 会暂停等待用户完成。 |
| **Saga 模式** | Saga Pattern | 分布式事务补偿模式，通过反向操作回滚已完成的步骤。 |

## Skill 相关

| 术语 | 英文 | 定义 |
|------|------|------|
| **Skill** | Skill | 可复用的原子能力单元，封装特定业务逻辑。 |
| **Core Skill** | Core Skill | Delphi 实现的本地 Skill，高性能、无网络依赖。 |
| **Python Skill** | Python Skill | Python 实现的 AI Skill，通过 HTTP 桥接调用。 |
| **Skill 注册表** | Skill Registry | 军械官管理的 Skill 元数据和实例集合。 |

## 记忆相关

| 术语 | 英文 | 定义 |
|------|------|------|
| **工作记忆** | Working Memory | 单次请求期间的临时存储，任务结束后清除。 |
| **会话记忆** | Session Memory | 单次会话期间的上下文存储，包含对话历史和意图追踪。 |
| **长期记忆** | Long-term Memory | 跨会话持久化的用户知识，包含偏好、经验、知识图谱。 |
| **上下文窗口** | Context Window | 发送给 LLM 的对话历史子集，受 token 限制约束。 |
| **向量检索** | Vector Search | 基于语义相似度的记忆检索方式。 |

## 消息相关

| 术语 | 英文 | 定义 |
|------|------|------|
| **Command** | Command | 请求执行操作的消息类型，需要响应。 |
| **Event** | Event | 通知已发生事实的消息类型，无需响应。 |
| **Query** | Query | 查询信息的消息类型（技术上属 Command 的子类），不改变状态。 |
| **correlationId** | Correlation ID | 关联一次业务请求的唯一标识。 |
| **traceId** | Trace ID | 分布式追踪标识，用于跨角色日志关联。 |
| **幂等键** | Idempotency Key | 保证请求幂等性的唯一键，相同键不会重复执行。 |

## 安全相关

| 术语 | 英文 | 定义 |
|------|------|------|
| **入口校验** | Entry Validation | 守卫对用户输入的安全检查，包括格式、注入检测。 |
| **出口审核** | Exit Validation | 守卫对 AI 输出的安全检查，包括内容合规、幻觉检测。 |
| **熔断** | Circuit Breaker | 外部服务连续失败时自动切断调用的保护机制。 |
| **背压** | Backpressure | 系统过载时拒绝新请求的流量控制机制。 |
| **降级** | Degradation | 部分功能不可用时提供简化服务的容错策略。 |

| 术语 | 英文 | 定义 |
