# DeepFlow 可观测性设计

> 定义 DeepFlow 系统的可观测性三支柱：日志(Logging)、指标(Metrics)、追踪(Tracing)）

创建日期: 2025-12-04  版本: 1.0

---

## 1. 概述

### 1.1 设计目标

- **问题快速定位**：从告警到根因 < 5 分钟
- **全链路可追溯**：请求从入口到出口完整可见
- **性能瓶颈识别**：热点角度(Skill 一目了然)
- **成本可控**：日志存储和查询成本合理

### 1.2 三支柱架构

```
┌─────────────────────────────────────────────────────────────────────┐
│                       DeepFlow 可观测性                             │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │

│ │    日志        │ │    指标        │ │    追踪        │    │
│ │  (Logging)     │ │  (Metrics)     │ │  (Tracing)     │    │
│ │                │ │                │ │                │    │
```

## 2. 日志系统 (Logging)

### 2.1 日志格式

所有日志采用结构化 JSON 格式。

```json
{
  "timestamp": "2025-12-04T10:30:15.123Z",
  "level": "info",
  "traceId": "abc123def456",
  "spanId": "span789",
  "role": "Commander",
  "action": "REQUEST_RECEIVED",
  "message": "接收用户请求",
  "data": {
    "userId": "u-001",
    "requestType": "analyze",
    "inputLength": 256
  },
  "duration_ms": 15,
  "error": null
}
```

### 2.2 日志级别

| 级别 | 用途 | 示例 | 生产环境 |
|------|------|------|----------|
| **TRACE** | 详细调试信息 | 变量值、循环迭代 | 关闭 |
| **DEBUG** | 调试信息 | 方法入口/出口、参数 | 关闭 |
| **INFO** | 业务关键事件 | 请求开始/结束、状态变更 | 开启 |
| **WARN** | 潜在问题 | 重试、降级、接近阈值 | 开启 |
| **ERROR** | 错误但可恢复 | 单次失败、外部服务错误 | 开启 |
| **FATAL** | 严重错误 | 系统无法继续运行 | 开启 |

### 2.3 角色日志规范

每个角色必须记录的日志要点

| 角色 | 必记录日志 |
|------|------------|
| **Engine** | 角色启动/停止、消息路由、心跳状态 |
| **Commander** | 请求接收、任务分解、最终响应 |
| **Dispatcher** | Workflow 创建/状态变更、步骤执行 |
| **Advisor** | LLM 请求/响应、Token 使用、置信度 |
| **Executor** | Skill 开始/结束、输入输出摘要 |
| **Guard** | 校验结果、拦截原因、安全事件 |
| **Quartermaster** | 资源分配、配额变更、缓存命中 |
| **Chronicler** | 记忆存储/召回、审计事件 |
| **SignalOfficer** | 外部调用请求/响应、熔断状态 |

### 2.4 Delphi 日志接口

```pascal
type
  TUniFlowLogger = class
  private
    FTraceId: string;
    FRole: string;
  public
    constructor Create(const ARole: string);
    
    procedure Trace(const AAction, AMessage: string; AData: TJSONObject = nil);
    procedure Debug(const AAction, AMessage: string; AData: TJSONObject = nil);
    procedure Info(const AAction, AMessage: string; AData: TJSONObject = nil);
    procedure Warn(const AAction, AMessage: string; AData: TJSONObject = nil);
    procedure Error(const AAction, AMessage: string; AError: Exception = nil);
    procedure Fatal(const AAction, AMessage: string; AError: Exception = nil);
    
    // 设置追踪上下文
    procedure SetTraceContext(const ATraceId, ASpanId: string);
    
    // 创建子Logger（继承TraceId）
    function CreateChild(const ARole: string): TUniFlowLogger;
  end;

// 使用示例
procedure TCommander.HandleRequest(const ARequest: TUserRequest);
var
  LLogger: TUniFlowLogger;
begin
  LLogger := TUniFlowLogger.Create('Commander');
  LLogger.SetTraceContext(ARequest.TraceId, GenerateSpanId);
  
  LLogger.Info('REQUEST_RECEIVED', '接收用户请求', 
    TJSONObject.Create
      .AddPair('userId', ARequest.UserId)
      .AddPair('type', ARequest.RequestType)
  );
  
  try
    // 处理请求...
    
    LLogger.Info('REQUEST_COMPLETED', '请求处理完成',
      TJSONObject.Create.AddPair('duration_ms', LStopwatch.ElapsedMilliseconds)
    );
  except
    on E: Exception do
    begin
      LLogger.Error('REQUEST_FAILED', '请求处理失败', E);
      raise;
    end;
  end;
end;
```

## 3. 指标系统 (Metrics)

### 3.1 指标类型

| 类型 | 说明 | 使用场景 |
|------|------|----------|
| **Counter** | 单调递增计数 | 请求总数、错误总数 |
| **Gauge** | 可增可减的值 | 当前活跃连接、队列长度 |
| **Histogram** | 值分布统计 | 响应时间、消息大小 |
| **Summary** | 分位数统计 | P50/P90/P99 延迟 |

### 3.2 核心指标清单

#### 3.2.1 系统级指标

| 指标名 | 类型 | 标签 | 说明 |
|--------|------|------|------|
| `deepflow_requests_total` | Counter | role, status | 请求总数 |
| `deepflow_request_duration_ms` | Histogram | role, action | 请求耗时分布 |
| `deepflow_active_workflows` | Gauge | status | 活跃 Workflow 状态|
| `deepflow_message_queue_size` | Gauge | role | 消息队列长度 |

#### 3.2.2 角色级指标

| 角色 | 指标 | 说明 |
|------|------|------|
| **Advisor** | `deepflow_llm_requests_total` | LLM 调用次数 |
| | `deepflow_llm_tokens_used` | Token 消耗量 |
| | `deepflow_llm_latency_ms` | LLM 响应延迟 |
| | `deepflow_llm_errors_total` | LLM 错误次数 |
| **Executor** | `deepflow_skill_executions_total` | Skill 执行次数 |
| | `deepflow_skill_duration_ms` | Skill 执行耗时 |
| | `deepflow_skill_errors_total` | Skill 错误次数 |
| **Guard** | `deepflow_guard_validations_total` | 校验次数 |
| | `deepflow_guard_rejections_total` | 拒绝次数 |
| | `deepflow_guard_injection_attempts` | 注入尝试检测|
| **SignalOfficer** | `deepflow_http_requests_total` | HTTP 请求总数 |
| | `deepflow_http_latency_ms` | HTTP 延迟 |
| | `deepflow_circuit_breaker_state` | 熔断器状态|

```pascal
      ATags: TArray<TTag> = nil);

    procedure DecGauge(const AName: string; AValue: Double = 1);
    
    // Histogram

      ATags: TArray<TTag> = nil);

// 使用示例
procedure TAdvisor.CallLLM(const APrompt: string);
var
  LStartTime: TStopwatch;
begin
  LStartTime := TStopwatch.StartNew;
  
  try
    // 调用 LLM...
    
    FMetrics.IncCounter('deepflow_llm_requests_total', 1, [
      TTag.Create('model', FCurrentModel),
      TTag.Create('status', 'success')
    ]);
    
    FMetrics.ObserveHistogram('deepflow_llm_latency_ms', 
      LStartTime.ElapsedMilliseconds, [
      TTag.Create('model', FCurrentModel)
    ]);
    
    FMetrics.IncCounter('deepflow_llm_tokens_used', LTokensUsed, [
      TTag.Create('type', 'input')
    ]);
  except
    FMetrics.IncCounter('deepflow_llm_requests_total', 1, [
      TTag.Create('model', FCurrentModel),
      TTag.Create('status', 'error')
    ]);

  end;
end;
```

## 4. 分布式追踪(Tracing)

### 4.1 追踪模型

```
Trace (完整请求)
├── Span: Commander.HandleRequest
├── Span: Dispatcher.CreateWorkflow
步骤  ├── Span: Dispatcher.CreateWorkflow
步骤 步骤  ├── Span: Executor.RunSkill (decision_coach)
步骤 步骤 步骤  └── Span: SignalOfficer.CallLLM
步骤 步骤  └── Span: Executor.RunSkill (film_generator)
步骤  └── Span: Guard.ValidateOutput
└── Span: Chronicler.AuditLog
```

### 4.2 Trace 与 Span 结构

```pascal
type
  TTraceContext = record
     TraceId: string;      // 全局唯一，贯穿整个请求
    SpanId: string;       // 当前 Span ID
     ParentSpanId: string; // 父 Span ID
     Baggage: TDictionary<string, string>; // 传递的上下文数据
  end;

  TSpan = record
    TraceId: string;
    SpanId: string;
    ParentSpanId: string;
     OperationName: string;    // 如"Commander.HandleRequest"
    StartTime: TDateTime;
    EndTime: TDateTime;
    Duration_ms: Int64;
    Status: TSpanStatus;      // OK, ERROR, TIMEOUT
    Tags: TDictionary<string, string>;
    Logs: TArray<TSpanLog>;   // 过程中的事件
  end;
```

### 4.3 追踪传播

**角色间传播。**

```pascal
// 发送消息时携带 TraceContext
procedure TEngine.Route(const AMessage: TRoleMessage);
begin
  // TraceContext 自动附加到消息头
  AMessage.Headers['X-Trace-Id'] := FCurrentContext.TraceId;
  AMessage.Headers['X-Span-Id'] := FCurrentContext.SpanId;
  AMessage.Headers['X-Parent-Span-Id'] := FCurrentContext.ParentSpanId;
  
  // 路由消息...
end;

// 接收消息时恢复 TraceContext
procedure TDispatcher.HandleMessage(const AMessage: TRoleMessage);
var
  LContext: TTraceContext;
begin
  LContext.TraceId := AMessage.Headers['X-Trace-Id'];
  LContext.ParentSpanId := AMessage.Headers['X-Span-Id'];
   LContext.SpanId := GenerateSpanId;  // 新建一个 Span
  
  FTracer.StartSpan('Dispatcher.HandleMessage', LContext);
  try
    // 处理消息...
  finally
    FTracer.EndSpan;
  end;
end;
```

**跨服务传播（HTTP）。**

```pascal
// 调用 Python Skill 时传参
procedure TSignalOfficer.CallPythonSkill(const ARequest: TSkillRequest);
begin
  FHttpClient.Headers['X-Trace-Id'] := FCurrentContext.TraceId;
  FHttpClient.Headers['X-Span-Id'] := FCurrentContext.SpanId;
  
  // 发起 HTTP 请求...
end;
```

### 4.4 Tracer 接口

```pascal
type
  ITracer = interface
     // 开始一个新的 Span
    function StartSpan(const AOperationName: string; 
      AParentContext: TTraceContext = nil): ISpan;
    
    // 获取当前 Span
    function CurrentSpan: ISpan;
    
// 注入 TraceContext 到载体（：HTTP Headers：
    procedure Inject(const ACarrier: TStrings);
    
// 从载体提取 TraceContext
    function Extract(const ACarrier: TStrings): TTraceContext;
  end;

  ISpan = interface
    procedure SetTag(const AKey, AValue: string);
    procedure Log(const AEvent: string; AData: TJSONObject = nil);
    procedure SetStatus(AStatus: TSpanStatus; const AMessage: string = '');
    procedure Finish;
  end;

// 使用示例
procedure TExecutor.ExecuteSkill(const ASkillName: string);
var
  LSpan: ISpan;
begin
  LSpan := FTracer.StartSpan('Executor.ExecuteSkill');
  LSpan.SetTag('skill.name', ASkillName);
  
  try
    // 执行 Skill...
    
    LSpan.Log('skill.started', TJSONObject.Create.AddPair('input_size', LInputSize));
    
    // ...
    
    LSpan.SetStatus(ssOK);
  except
    on E: Exception do
    begin
      LSpan.SetStatus(ssError, E.Message);
      LSpan.SetTag('error.type', E.ClassName);
      raise;
    end;
  end;
  
  LSpan.Finish;
end;
```

## 5. 统一关联

### 5.1 TraceId 规范

**格式**：`{timestamp_hex}-{random_hex}`

```
示例：18c5a2b3f-7d8e9f0a1b2c
      ├──────────┤├─────────────┤
      时间戳(ms)   随机部分
```

**生成规则**：
```pascal
function GenerateTraceId: string;
begin
  Result := Format('%x-%s', [
    DateTimeToUnix(Now) * 1000,  // 毫秒时间戳
    TGuid.NewGuid.ToString.Replace('-', '').Substring(0, 12)
  ]);
end;
```

## 7. 性能考虑

### 7.1 开销控制

| 操作 | 目标开销 | 策略 |
|------|----------|------|
| 日志写入 | < 0.1ms | 异步批量写入 |
| 指标更新 | < 0.01ms | 内存原子操作 |
| Span 创建 | < 0.05ms | 对象池复用 |
| TraceId 生成 | < 0.01ms | 简单算法 |

### 7.2 采样策略

**MVP 阶段**（流量小）：
- 日志 1 00% 采样
- 追踪 1 00% 采样
- 指标：无采样

**V1.0+**（流量增大后）：
- 日志：错误 100%，Info 10%
- 追踪：自适应采样（P99 延迟 > 阈值时提高采样率）
- 指标：无采样

### 7.3 存储优化

```pascal
// 日志异步写入
TAsyncLogWriter = class(TThread)
private
  FQueue: TThreadedQueue<TLogEntry>;
  FBatchSize: Integer;
  FFlushInterval: Integer;  // ms
protected
  procedure Execute; override;
public
  procedure Enqueue(const AEntry: TLogEntry);
end;

// 使用示例
procedure TUniFlowLogger.Info(const AAction, AMessage: string);
begin
  FAsyncWriter.Enqueue(TLogEntry.Create(
    llInfo, FRole, AAction, AMessage, FTraceId
  ));
end;
```
