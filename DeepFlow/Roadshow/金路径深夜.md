# 《深夜的胶片》

## 一、凌晨两点的电话

2026 年 8 月，凌晨两点十七分。

林深被电话震醒。电话那头是澄明医疗的信息总监老苏，声音哑得像砂纸：

"林工，董事会把我们批了——'智能客服'这方案毙了。董事会说，他们要的不是一个会答话的机器人，是一个**能替他们推演的参谋**。下周三汇报，你做不做得了？"

林深睡意全消。澄明医疗是他创业公司微澜科技的第一个大客户，五十多家连锁药房，老板们每周的采购、扩张、定价决策，全靠拍脑袋。老苏求了他三个月，方案交了三版：第一版是客服机器人，第二版是知识库问答，第三版加了推荐算法——全被否。

"推演……"林深握着电话，脑子飞速转，"你是说，把一个问题抛进去，系统从好几个角度分析，最后给出决策参考？"

"对。他们说得很玄——'要有过程，不要只给结论'。'我们想知道这个决定是怎么被想出来的。'"

林深看了一眼床头柜上摊开的《决策思维》，叹口气："我试试。周三见。"

挂了电话，他打开笔记本。屏幕上是他前天画的选型表格——一列是"拟用方案"，另一列是"为什么不行"。

## 二、江湖上的刀

林深这一周，把市面上能用的都试了一遍。他把这段经历叫作"试刀"。

**第一把刀，是 Apache Airflow。**

他先想到它。老牌工作流引擎，Python 生态，DAG 描述任务依赖，调度稳定得像钟表。他把六角色分析拆成六个 task，画成 DAG，跑通了。

然后他站在白板前发了十分钟呆。

"Airflow 是个**闹钟**，"他在复盘笔记里写，"它负责准时叫醒每一个任务，但它不负责任务之间怎么思考。我要的是参谋团，不是打卡机。而且它的调度器重、部署繁、UI 是给运维看的——客户要看的是一份'决策推演过程'，不是一张 DAG 图。"

**第二把刀，是 Temporal。**

圈子里口碑最好的持久化工作流引擎。Go 写的，重试、定时、活动补偿、确定性重放，工程上无懈可击——"能把一个跑了一半的工作流，从进程崩溃里原样捞回来接着跑"。他花了两天读文档，承认它确实是内功深厚的武林正宗。

"但 Temporal 是个**发动机**，"他写道，"它给你最可靠的传动系统，可业务逻辑全要你自己写。六个 AI 角色怎么协作？每个角色的提示词怎么设计？输出怎么校验？怎么防止'看起来成功了其实全是空话'？这些它一概不管。我得在上面再造半个平台。"

**第三把刀，是 n8n、Zapier 那一类。**

节点式低代码自动化，拖拖拽拽就能连上百个 SaaS。他五分钟就把"收到问题→调大模型→回消息"串成了流程图。

"它们擅长的是**集成**——把 Slack、邮箱、数据库黏在一起。但塞进节点里的 prompt 只是字符串拼接。当你的'流程'需要角色互相质疑、需要聚合六份分析、需要产出思维胶片的时候，节点连线就成了意大利面。"

**第四把刀，是 LangGraph。**

最接近答案的一个。LLM 应用编排的事实标准，图状态机，节点之间传状态，AI agent 圈里人人用它。林深认认真真试了两天，确实灵活——他甚至在图上画出了 coach、critic、mirror、observer 四个并行节点，再加一个聚合节点。

"但 LangGraph 给我的是**乐高**，"他叹气，"零件齐，图纸没有。可靠性——超时重试？我自己写。审计——每一步谁说了什么？我自己存。事件溯源、状态恢复、多租户隔离、权限、限流、仪表盘？全是我自己的活。我只有四个人，我不想把六个月花在造地基上。"

**第五把刀，是 Dify、Coze 那类 LLM 应用平台。**

对话流编排，十分钟出原型，Agent 一键接入。他承认这玩意做"聊天机器人"是降维打击。

"但它们的编排上限是**对话流**。我要的不是聊天记录，是一个可审计、可回放、可多租户隔离的**决策系统**。平台把一切都锁在自己的云里，我想深入每一层，却连门都打不开。"

周一的深夜，林深盯着那张选型表，五把刀摊在桌上，没有一把趁手。他给大学同窗、现在在某大厂做架构师的阿凯发了条消息：

"有没有一个东西——有工作流引擎的筋骨，有 AI 编排的脑子，还自带审计、事件溯源、多租户、可视化，像'操作系统'一样让下游软件随便接入？"

阿凯回得飞快：

"有。你听说过 DeepFlow 吗？"

## 三、智能应用的操作系统

阿凯发来一份文档的链接，开头第一行写着：

> **DeepFlow：智能应用的操作系统。**

"它不是某一个工具，"阿凯在语音里说，"它是一套完整的运行时：核心是一个工作流引擎，但引擎只是底座。上面有 Skills 服务——AI 技能以 HTTP 接口暴露，你的下游系统随便调；有事件溯源——每一步状态都落库，重启可以从断点恢复，出事可以回放；有多租户、有审计、有可视化编辑器、有分析仪表盘。最特别的是它内置了一套决策推演技能，叫 **DeepInsight**——六角色多视角分析，产出'思维胶片'。"

"思维胶片？"

"对。它家的哲学是：**决策的价值在过程，不在结论**。它把分析过程本身做成一份可读的'胶片'——怎么想、从哪几个角度想、哪些假设被挑战了、哪些盲区被点亮了——而不是只丢给你一个'建议'。"

林深脑子里"咔"地一声，接通了。老苏说的那句话："要有过程，不要只给结论。"

"接入方式呢？"他追问，"下游系统怎么用？"

"三种姿势。"阿凯如数家珍，"第一，**直接调 API**——它把工作流和技能都暴露成 REST 接口，`/skills/execute`、`/llm/chat`，POST 一个 JSON 进去，结果 JSON 出来，任何语言都能接；第二，**提交 Workflow 定义**——你写一份 JSON，描述步骤、条件、循环、并行，它来执行，Delphi 核心引擎负责跑，稳如老狗；第三，**MCP 接入**——它规划了 MCP 支持，AI 编程工具、智能体客户端可以直接把它当工具调用。"

"它甚至有 Delphi 客户端，"阿凯补了一句，"你们公司不是还有一堆老 Delphi 系统吗？一个 `TSkillClient` 就能从老系统里调它的技能——老树发新芽。"

林深看了一眼公司代码库——三个遗留 Delphi 系统，他天天想拆。他心动了。

"最后一个问题，"他问，"它自己靠谱吗？"

阿凯沉默了两秒："你问到点子上了。它曾经有个要命的缺陷，叫'假绿'。"

## 四、假绿之夜

周二，林深把 DeepFlow 拉下来跑通了。快得超乎想象。

他照着文档写了一份 Workflow 定义，JSON，干净得像诗：一个 `parallel` 步骤，同时扇出四个视角——**coach（决策教练）、critic（批判者）、mirror（反思者）、observer（观察者）**；四个视角完成后，进入 `aggregator`（聚合者）步骤，把四份分析揉成一份；最后是 `film_generator`（胶片生成器），把整个过程写成一份思维胶片。

下游系统接入也简单得离谱：微澜科技的 Web 端调 `/skills/execute`，传 `skill_name: "decision_insight"` 和问题文本，剩下的交给 DeepFlow。

第一次端到端跑通，他盯着控制台，六盏灯依次亮起，**全部显示成功**。

他差点欢呼。然后他干了件救命的活儿——把每个角色的原始返回打出来看。

他愣住了。

coach 的返回里，`key_insights: []`，`guiding_questions: []`——**全是空的**。可日志里分明写着"成功"。

他去找阿凯。阿凯在电话里笑了："你踩到'假绿'了。大模型不老实，你让它输出 JSON，它给你回一篇 Markdown 抒情散文。DeepFlow 早期的解析器太宽容，解析失败就悄悄退回空结构，但标记 `degraded=False`——看起来全绿，实际上全是废料。我们管这叫**绿路径假绿**。"

"那后来呢？"

"后来它修了，而且是三重防护。第一，**System Prompt 钉死**：每个角色的提示词末尾都加上'重要：只输出一个纯 JSON 对象，不要 Markdown，不要代码围栏，不要解释'；第二，**解析器增强**：就算模型不听话、包了 ```json 围栏，也能把 JSON 从围栏里剥出来；第三，最关键——**主动降级**：一旦发现返回里带着原始文本（`raw_analysis`）而不是结构化数据，立刻判定'这次 LLM 没干活'，主动降级到内置模板，并且把 `degraded` 标记成 `True`、写下降级原因。宁可让你看见红灯，也不让你把假绿当成功。"

"诚实，"林深说，"这是个愿意承认自己失败的引擎。"

"还有两个坑，你今晚大概率也会踩。"阿凯继续，"第一，**截断**：真实聚合数据动辄几千 token，`max_tokens` 设小了，JSON 被一刀切断，解析必挂。后来它把聚合器和胶片生成器的 `max_tokens` 提到了 8192，还给聚合器加了输入压缩——每类洞察最多留三条，每条最多 200 字。第二，**超时**：四角色并发还好，一旦串行排队，单角色二十多秒，整个链路能逼近两分钟。默认超时从 30 秒提到 120 秒，演示脚本直接给到 300 秒。"

林深默默把这三个数字记在笔记本上：**8192、120、300**。

## 五、金路径

周三，上午九点，澄明医疗董事会会议室。

林深只带了一台笔记本，连了一根 HDMI 线。投影幕布上，是 DeepFlow 的可视化编辑器里那张工作流图——六角星一样优雅的拓扑：四路并行、一聚合、一胶片。

"各位，"他说，"请给我一个问题。真实的、你们下周要做的决策。"

老苏清了清嗓子："直营门店要不要从五十家扩到八十家？预算八千万，周期两年。"

林深敲下回车。

屏幕上，四个角色同时亮起，各自的思考像流水一样滚动：

- **教练**在拆解目标：扩张的财务模型、现金流压力、选址逻辑；
- **批判者**在进攻：八千万砸进去，如果明年医保政策变动呢？店均客流下降 5% 意味着什么？
- **反思者**在照镜子：'我们有赌赢的冲动吗？'——决策者的自信是不是来自去年的一次侥幸；
- **观察者在数事实**：区域人口密度、竞品门店数、最近 12 个月单店盈亏曲线，全部来自澄明自己的数据。

八十九点五秒后，聚合节点亮起，随后，胶片生成器吐出了一份文档——**《决策思维胶片：直营扩张 50→80 家》**。

胶片没有直接说"做"或"不做"。它把整个过程摊开了：四个视角各自的立场、关键分歧点、共识区间、被挑战的假设、被点亮的盲区，最后是三条"如果必须做，必须盯住的闸门指标"。

会议室安静了十几秒。

老苏先开口，声音有点抖："这东西……把我们开会的过程，变成了一个可以反复放的东西。"

董事长说了一句让林深记到现在的话："结论会过时，过程不会。这份胶片，三个月后还能拿出来复盘。八千万的决策，值了。"

林深在回程的高铁上，给阿凯发了条消息："金路径闭环了。请求进，胶片出。六盏灯全绿——这次是真的绿，`degraded=False`，每一盏。"

阿凯回了一个大拇指。

## 六、武器谱

林深后来在公司 wiki 里写了一篇复盘，标题叫《武器谱》，把这几天的选型对比沉淀了下来。他写道：

> **Airflow** —— 调度之王，数据管道的闹钟。适合"定时跑批"，不适合"AI 参谋团"。它告诉你任务何时跑，不告诉你任务怎么想。
>
> **Temporal** —— 持久化内功第一。崩溃恢复、重试、补偿，工程典范。但它是发动机，不是整车——AI 协作、输出校验、审计、多租户，全得自己造。
>
> **n8n / Zapier / Make** —— 集成胶水，SaaS 万能插座。流程长在节点连线里，塞不进"角色互驳、聚合、胶片"这种需要智力的编排。
>
> **LangGraph / LangChain** —— LLM 编排的乐高。状态机灵活到极致，但地基自理：可靠性、可观测、审计、多租户，零件都在，图纸没有。
>
> **Dify / Coze / FastGPT** —— LLM 应用平台的快捷酒店。十分钟入住，但天花板是对话流；它是平台的产品，你不是平台的主人。
>
> **Camunda / Argo** —— 企业流程与 K8s 原生，BPMN 正统与容器编排的猛将，但面向"审批流"和"CI 部署"，与"决策推演"两个世界。
>
> **DeepFlow** —— 智能应用的操作系统。工作流引擎是筋骨，Skills 服务是器官，事件溯源是记忆，审计是良心，可视化编辑器是脸面，DeepInsight 六角色推演是大脑，思维胶片是灵魂。下游软件通过 REST API、Workflow 定义、MCP、甚至 Delphi 客户端接入——它不抢你做应用，它给你做应用的底座。

最后一行，他用加粗写了一句：

> **最打动我的不是它有多强，而是它拒绝假绿——一个愿意承认自己失败的引擎，才值得把决策交给它。**

凌晨，微澜科技的办公室里只剩林深一个人。屏幕上还开着那份胶片，结尾写着：

> *决策的价值，不在结论的正确，而在过程的诚实。*

他把屏幕合上，看了一眼窗外。天快亮了。
