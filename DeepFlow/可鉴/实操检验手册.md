## 🎮 实操检验步骤

### Step 1: 确认服务状态

打开新终端窗口：
```powershell
# Check Skills service health
curl http://127.0.0.1:8001/health

# Check HTTP server status
curl http://127.0.0.1:8090
```

预期输出:
- `/health` → JSON: `{"status":"healthy","skills_loaded":7,...}`
- `/8090` → HTML content of index.html

### Step 2: 打开预览浏览器

点击上方工具面板中的 **"可鉴决策操作系统"** 按钮，或手动访问:
```
http://127.0.0.1:8090
```

### Step 3: 体验完整流程

**推荐测试问题 (按复杂度递增):**

1. **入门测试** (简单):
   > "是否要推出新款智能硬件？预计研发投入 500 万，目标市场一线城市。"

2. **中等难度**:
   > "直营门店要不要从 50 家扩到 80 家？预算 8000 万，周期两年。"

3. **复杂挑战**:
   > "公司是否要转型做 SaaS 产品？现有业务稳定但增长乏力，需要投入 X 资金培养新团队。"

**操作指引:**
1. 在输入框粘贴上述问题
2. 选择治理模板（默认"战略决策"即可）
3. 点击"开始治理"按钮
4. **观察进度**:
   - 四角色并行推演状态（绿色 = OK，黄色 = 降级，红色 = 失败）
   - 实时倒计时（预计 2-4 分钟）
5. 查看聚合共识（情绪光谱、四视角摘要、关键洞察）
6. 阅读胶片输出（结构化 HTML，含自我提问清单）
7. 点击"生成分享卡片"并下载 PNG
8. 检查底部水印（品牌标识）

### Step 4: 验证分享功能

1. 完成一次治理后，点击"生成分享卡片"
2. 查看弹窗中展示的卡片效果（Logo+ 标题 + 问题 + 角色徽章）
3. 点击下载按钮保存 PNG
4. **验证内容**: 卡片应包含品牌水印和邀请文案

### Step 5: API 调试（可选）

**手动调用 Skills API 验证:**

```powershell
# 单个技能调用
$body = @{
    skill_name = "decision_coach"
    params = @{
        problem = "测试中文内容"
        context = @{ decision_type = "strategic" }
    }
    context = @{}
    timeout_ms = 300000
} | ConvertTo-Json -Depth 5

Invoke-RestMethod `
    -Uri "http://127.0.0.1:8001/skills/execute" `
    -Method Post `
    -Body $body `
    -ContentType "application/json" `
    -TimeoutSec 290
```

**验证要点:**
- `result.degraded` 应为 `false`（如果 LLM 正常响应）
- `result.key_DeepInsights` 应包含实际洞察数组
- `result.guiding_questions` 应有 3-5 个问题
- `execution_time_ms` 通常在 20000-100000ms 范围

## 🐛 已知限制与说明

### 1. 中文传输稳定性
**现象**: 部分请求可能返回 `llm_response_not_json` 降级  
**原因**: PowerShell UTF-8→GBK 编码转换可能导致字符损坏  
**解决**: 
- E2E 测试已改用 ASCII 兼容输出（如 `[OK]`替代`✓`）
- 前端 JS 不受影响（浏览器 UTF-8 原生支持）
- 建议生产环境部署时用 Node.js/Go 客户端替代 PowerShell

### 2. 性能基准
**单次治理耗时**: 2-4 分钟（6 个串行 LLM 调用）  
**并发限制**: 不建议同时进行超过 3 次完整治理  
**优化方向**: 
- 引入 WebSocket 流式输出减少等待感
- 缓存历史问题结果避免重复计算

### 3. 降级策略
**原则**: 宁可降级也不假绿  
**降级可见性**: 所有降级明确标记为`⚠降级原因`  
**兜底价值**: 即使降级仍能提供引导问题和基础洞察
