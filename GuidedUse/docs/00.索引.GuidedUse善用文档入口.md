## 2. 当前定位

善用 GuidedUse 是一个桌面悬浮式软件任务陪跑系统。

它悬浮在用户正在使用的软件或网页旁边，通过步骤引导、原截图、简笔线框图、FocusSketch 聚焦导航、卡点问答和 LostRecovery 迷路恢复，帮助用户不用来回切教程，也能一步步完成新软件里的真实任务。

第一阶段不做：

```text
自动点击
自动填写
重 RPA
复杂 UI Automation
企业权限
高合规大 B 项目
完整知识库平台
```

第一阶段先做：

```text
GuidePackage 善用包
桌面悬浮播放器
简笔框线图 / FocusSketch
步骤播放
已完成 / 我迷路了 / 找不到按钮
DeepLaunch 样板善用包
本地保存与后续云端同步预留
```
