# GuidedUse 善用后继问题讨论

---

## 已确认决策

```text
1. 中文名保留：善用。
2. 英文名采用：GuidedUse。
3. 产品定位：桌面悬浮式软件任务陪跑系统。
4. 第一阶段不做重 RPA，不做自动点击，不做大 B 投标系统。
5. 第一阶段先服务自己软件矩阵和普通用户上手场景。
6. 第一条重点样板：善用指导 DeepLaunch 绑定第一个快速启动程序。
7. 后台可由 OCGS 指导，但对外先讲人话。
```
