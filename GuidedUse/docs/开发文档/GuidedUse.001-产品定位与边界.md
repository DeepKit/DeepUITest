# GuidedUse.001 - 产品定位与边界

> 状态：开发文档初版
> 用途：冻结善用第一阶段的产品定位、用户、边界和表达口径

---

## 1. 产品名

```text
中文名：善用
英文名：GuidedUse
```

英文副标题：

```text
GuidedUse helps users complete real software tasks, step by step.
```

中文传播语：

```text
新软件不会用？善用一步步带你用。
```

---

## 2. 产品定位

```text
善用 GuidedUse 是一个桌面悬浮式软件任务陪跑系统。
```

完整定义：

```text
善用悬浮在用户正在使用的软件或网页上方，
通过步骤引导、原截图、简笔线框图、FocusSketch 聚焦导航、卡点问答和 LostRecovery 迷路恢复，
帮助用户不用来回切教程，也能一步步完成新软件里的真实任务。
```

核心目标：

```text
不是让用户学完整个软件，而是让用户先完成第一件有价值的事。
```

## 3. 它不是这些东西

```text
软件教程平台
视频课程
普通说明书
知识库
普通 AI 问答
RPA 自动点击工具
自动填写工具
企业大投标系统
完整 UI Automation 平台
```

---

## 4. 它是什么

```text
软件任务陪跑系统
桌面悬浮式场域导航系统
新软件首次成功任务引导器
软件使用旅程包播放器
AI 辅助生成软件引导包的工具
```

核心差别：

```text
普通教程：教你这个软件有什么功能。
善用：带你用这个软件完成一件事。
```

---

## 5. 第一阶段用户

优先面向：

```text
1. 自己和自研软件用户。
2. 拿到新软件但不想看长教程的普通用户。
3. 独立软件作者。
4. 小团队内部工具用户。
5. AI 工具用户。
```

暂不优先：

```text
1. 大企业。
2. 政务大厅。
3. 银行柜面。
4. 税务局。
5. 电信营业厅。
6. 高合规大 B 场景。
```

---

## 6. 第一阶段产品边界

第一阶段优先做：

```text
1. 本地 GuidePackage。
2. 桌面悬浮播放器。
3. 简笔框线图 / FocusSketch。
4. StepInstruction 步骤提示。
5. VisualAnchor 视觉锚点。
6. RouteRule 路由。
7. LostRecovery 迷路恢复。
8. TraceEvent 卡点记录。
9. DeepLaunch 样板善用包。
```

第一阶段暂缓：

```text
1. 自动点击。
2. 自动填写。
3. 重 RPA。
4. 复杂 OCR。
5. 浏览器插件。
6. 企业权限。
7. 多人协作。
8. 行业专家库。
9. 完整云端市场。
10. AI 线框生成器正式发布。
```

## 7. 技术形态

建议形态：

```text
本地桌面端 + 本地缓存 + 后续云端能力库。
```

数据部署冻结：

```text
DB1：本地 DeepBase config.db，存配置、路径、偏好和 API 端点。
DB2：本地 SQLite 业务库，存 GuidePackage 索引、FocusSketch 草稿、TraceEvent 和离线缓存。
DB3：公网 PG 业务后端，存云端善用包、模板市场、同步数据、统计和 AI 任务记录；桌面端只走 HTTPS API。
DB4：DeepBase 框架统一认证支付后端，存账号、订单、支付、订阅和权益；GuidedUse 只集成 DeepBase Commerce/Auth 模块。
```

桌面端负责：

```text
悬浮显示
目标窗口绑定
步骤播放
FocusSketch 渲染
用户交互
本地缓存
TraceEvent 记录
```

云端后续负责：

```text
善用包同步
版本更新
模板市场
AI 线框生成
受控问答
卡点统计
账号与授权
```

云端能力不等于客户端直连数据库；GuidedUse 桌面端只连接 DB3 业务 API，并通过 DeepBase Commerce/Auth 框架使用 DB4 能力，不连接公网 PG 或支付认证库。

---

## 8. 当前冻结句

```text
善用 GuidedUse 不是教程平台，也不是 RPA。
它是一个桌面悬浮式软件任务陪跑系统：
当用户拿到新软件不知道怎么用时，
善用悬浮在软件旁边，用步骤、图卡、FocusSketch、视觉锚点和迷路恢复，
带用户完成一个真实任务。
```
