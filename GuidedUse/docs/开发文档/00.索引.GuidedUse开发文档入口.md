## 1. 当前冻结判断

```text
1. 中文名：善用。
2. 英文名：GuidedUse。
3. 定位：桌面悬浮式软件任务陪跑系统。
4. 第一阶段：先自用、先轻产品、先服务普通用户和自研软件矩阵。
5. 不做：重 RPA、自动点击、自动填写、大 B 投标系统、复杂 UI Automation。
6. 先做：GuidePackage、FocusSketch、桌面悬浮播放器、LostRecovery、DeepLaunch 样板善用包。
7. 后台可由 OCGS 指导，对外先讲人话。
8. 数据部署：DeepBase DB1 + DB2 本地优先；DB3 走产品业务 API；DB4 统一走 DeepBase Commerce/Auth 框架，桌面端不直连公网 PG 或支付认证库。
```

## 5. 第一工程入口

第一版不要从 AI 线框生成器开始，也不要从云端市场开始。

第一工程入口是：

```text
本地 GuidePackage JSON
  -> 桌面悬浮播放器加载
  -> 显示当前 StepInstruction
  -> 渲染 FocusSketch
  -> 用户点击已完成 / 我迷路了
  -> RouteRule 跳转下一步或 LostRecovery
  -> TraceEvent 记录卡点
```

这个闭环跑通后，再做编辑器、AI 线框草稿、云端同步。
