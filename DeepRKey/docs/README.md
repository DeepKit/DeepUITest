## 前置知识

阅读 02.技术方案.md 前，建议了解以下概念：

| 概念 | 推荐资源 |
|------|----------|
| Win32 Hook（SetWindowsHookEx） | MSDN: Hooks Overview |
| 内存映射文件（CreateFileMapping） | MSDN: Memory-Mapped Files |
| 命名管道（CreateNamedPipe） | MSDN: Named Pipes |
| Win32 安全模型（DACL/SDDL） | MSDN: Access Control |
| Delphi 13.1 基础 | Delphi 内置文档 |

如果没有 Hook 编程经验，建议先阅读 `GLOSSARY.md` 中的术语表，再对照 `02.技术方案.md` 的数据流图（§3）建立心智模型。
