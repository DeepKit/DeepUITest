## 3. 各版本详细说明

### 3.1 开源版 (Community)

**目标用户**：开发者、开源社区、小团队试用

**核心功能**：
- 基础代理能力（多 Provider 支持、格式兼容、流式响应）
- 基础安全审计（绝对门禁、默认宪法）
- 基础审计日志（保留 7 天）
- 私有化部署

**不包含**：
- 响应门禁
- 质疑引擎
- 自定义宪法
- 账号池管理
- 企业功能

**适用场景**：
- 个人开发者试用
- 开源社区贡献
- 学习和了解产品

---

### 3.2 Team 版

**目标用户**：中小团队、创业公司

**核心功能**：
- 包含开源版所有功能
- 响应门禁（输出合规检查）
- 审计日志保留 30 天
- 日志导出功能
- 账号池管理（负载均衡、自动切换）
- 熔断器保护
- API 限流控制
- 邮件支持

**不包含**：
- 质疑引擎
- 自定义宪法
- 企业功能 (SSO/RBAC)

**适用场景**：
- 10-50 人研发团队
- 有基本安全合规需求
- 需要稳定可靠的代理服务

---

### 3.3 Enterprise 版

**目标用户**：大型企业、金融/医疗/政府等强监管行业

**核心功能**：
- 包含 Team 版所有功能
- 质疑引擎（请求合理性分析）
- 自定义宪法条款
- 宪法版本管理
- 审计日志永久保留
- 合规报告生成（ISO 27001 / SOC 2 / 等保）
- SSO 单点登录（SAML/OIDC）
- RBAC 权限管理
- 多租户支持
- 专属客户经理
- 7x24 技术支持
- SLA 保障 (99.9% 可用性)

**适用场景**：
- 100+ 人研发团队
- 金融/医疗/政府等强监管行业
- 有严格安全合规要求
- 需要私有化部署

## 6. 核心价值主张

### 6.1 为什么选择我们？

| 版本 | 核心价值 |
|------|---------|
| **开源版** | 免费、开源、自主可控 |
| **Team** | 完整双层审计、稳定可靠 |
| **Enterprise** | 合规保障、企业级功能、专属服务 |

### 6.2 竞争优势

1. **效率 + 安全双保险**：唯一同时满足"效率"和"安全"的代理
2. **物理拦截**：硬约束无法绕过，不是"建议"
3. **责任可追溯**：完整审计日志
4. **部署简单**：改一个 API 地址就能用
5. **成本可控**：Token 压缩、多账号优化
