# DeepSpec 深范｜后续讨论清单

## 1. 已经基本定下来的内容

### 1.1 产品名

**DeepSpec｜深范**

### 1.2 核心定位

**AI Coding 时代的旁路规格治理系统。**

### 1.3 技术路线

- Delphi；
- VCL；
- WebView2 / TEdgeBrowser；
- YAML；
- HTML；
- 本地文件系统；
- Git Diff 旁路读取；
- 可选 SQLite 缓存。

### 1.4 产品边界

不接管：

- IDE；
- CLI；
- Codex；
- Claude Code；
- Cursor；
- Copilot。

只做旁路：

- Context Pack；
- Trace；
- Review Pack；
- Spec Impact；
- Spec Inspector；
- Handoff Pack。

### 1.5 主界面

主窗体：

```text
顶部工具栏 + 左树 + 右 WebView2 + 状态栏
```

Spec Inspector：

```text
属性｜问题｜决定
```

## 2. 下一轮优先讨论

### 2.1 MVP 具体 Delphi 工程结构

需要确定：

- `UMainForm.pas`
- `USpecInspectorForm.pas`
- `USpecRepository.pas`
- `USpecCommandDispatcher.pas`
- `USpecEventBus.pas`
- `UYamlLoader.pas`
- `UHtmlRenderer.pas`
- `UGitDiffReader.pas`

各自职责和最小接口。

---

### 2.2 YAML 解析库选择

需要讨论：

- Delphi 中使用哪种 YAML 解析方案；
- 是否先用 JSON 替代 YAML；
- 是否让 YAML 只作为外部格式，内部转 JSON；
- 是否先用简单字段解析跑通 MVP。

---

### 2.3 HTML 模板引擎

需要讨论：

- 是否自写轻量模板；
- 是否使用 Mustache 类模板；
- CSS 是否统一；
- 每类 Spec 的 HTML 卡片结构；
- Review Pack 的 HTML 展示方式。

---

### 2.4 Git Diff 读取方式

需要讨论：

- 直接调用 `git` 命令；
- 还是使用 Git 库；
- 如何处理项目未初始化 Git；
- 如何处理大 diff；
- 如何识别变更影响的 Spec。

---

### 2.5 Context Pack 生成规则

需要讨论：

- 用户从哪里输入“当前任务”；
- Context Pack 选择哪些 Spec；
- 是否支持手动勾选关联文档；
- 输出 Markdown 还是 YAML；
- 是否提供复制按钮。

---

### 2.6 Review Pack 生成规则

需要讨论：

- 如何从 Git Diff 生成摘要；
- 如何判断影响哪些 Spec；
- 如何把 Review Pack 的问题转入 Spec Inspector；
- 是否允许用户编辑 Review Pack；
- 如何写入变更日志。

---

### 2.7 Spec Impact Analyzer

需要讨论：

- 文件类型与 Spec 的映射；
- UI 文件变化影响界面展示；
- 接口文件变化影响接口定义；
- 状态机代码变化影响状态机文档；
- 配置变化影响技术方案；
- 测试变化影响测试规格。

---

### 2.8 DeepSpec 与 DeepUITest 的衔接

需要讨论：

- 从功能树生成测试点；
- 从界面展示生成 UI 测试配置；
- 从 Review Pack 生成回归测试建议；
- DeepUITest 结果如何回写 DeepSpec。

---

### 2.9 Delphi Pack 是否作为第一扩展包

建议讨论：

**DeepSpec Delphi Pack**

功能可能包括：

- 扫描 `.dpr / .dproj / .pas / .dfm`；
- 生成窗体清单；
- 生成事件处理器清单；
- 生成菜单/Action/Button 对照表；
- 生成老项目交接卡；
- 生成 AI 读取顺序。

---

### 2.10 商业版边界

需要讨论：

- Free 版；
- Pro 版；
- Delphi Edition；
- Studio 版；
- Team / Enterprise 版。

以及哪些功能可以收费：

- 多项目；
- Review Pack；
- Delphi Pack；
- Handoff Pack；
- 健康度评分；
- DeepUITest 联动。

---

## 3. 后续开发建议顺序

1. 建 VCL 主窗体；
2. 加 WebView2 加载本地 HTML；
3. 建项目目录结构；
4. 读取 `deepspec.project.yaml`；
5. 扫描九类 Spec；
6. 生成左树；
7. 打开 Spec Inspector；
8. 显示属性；
9. 做基础 Schema 检查；
10. 显示问题；
11. 做决定页；
12. 做 HTML 生成；
13. 做 Context Pack；
14. 做 Git Diff / 文件变化扫描；
15. 做 Review Pack；
16. 做 Handoff Pack。
