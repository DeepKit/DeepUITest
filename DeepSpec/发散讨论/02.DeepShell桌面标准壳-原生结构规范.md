# DeepShell 桌面标准壳：原生结构规范

## 1. 定位

DeepShell 是一个可复用于多个 Windows 桌面软件的原生界面结构模板，不是 DeepSpec 的临时界面方案，而是后续 Delphi/VCL 框架可以内置的标准 Shell。

适用对象包括 DeepSpec、DeepUITest、DeepGuide Studio、DeepConfig、DeepDev、OCGS-Delphi 工具、ShineOps 管理端及其他 Windows 桌面工具型软件。

## 2. 总体原则

> 主窗体轻，中间工作；左右悬浮，多区多页；上下折叠，多 Tab 承载。

或：

> 左右悬浮，中间工作；上下可折叠。

## 3. 主窗体结构

```text
+--------------------------------------------------+
| ① 工具栏                                          |
+--------------------------------------------------+
| ② 顶部可折叠摘要区 / 多页区                       |
+--------------------------------------------------+
| ③ 中部主工作区 / 主浏览区 / 主编辑区               |
+--------------------------------------------------+
| ④ 底部可折叠信息区 / 日志区 / 多 Tab 区            |
+--------------------------------------------------+
```

主窗体不做重型 IDE，不固定塞满左中右三栏。

## 4. 工具栏

工具栏放高频操作：打开、保存、扫描、刷新、导出、结构窗、探查窗、日志、设置。复杂能力进入下拉菜单或悬浮窗。

## 5. 顶部可折叠摘要区

用于显示项目摘要、扫描统计、当前基准、最近变更、当前任务、关键指标。折叠后只保留一行摘要，例如：

```text
DeepSpec 项目｜Delphi VCL｜Pas 42｜DFM 6｜候选功能 23｜扫描完成
```

## 6. 中部主工作区

中部是主窗体最大区域，可承载 WebView2 浏览器、主编辑器、报告呈现区、设计画布、表格主视图等。

DeepSpec 中主要是 WebView2 主呈现区，用于显示扫描报告、文档详情、节点详情、AI 参考摘要、代码文件说明、配置文件说明、决定记录和变更记录。

## 7. 底部可折叠信息区

用于承载状态、日志、问题、错误、操作记录、变更记录、调试信息。折叠后只保留简短状态栏。

## 8. 左侧悬浮窗：结构 / 导航窗

左侧能力不固定在主窗体中，而是做成可打开、隐藏、置顶、锁定、记忆位置的悬浮工具窗。

职责：结构树、导航树、目录树、对象树、功能树、模块树、UI 层次树、项目资源树、搜索结果、过滤器、最近节点、异常节点。

推荐结构：

```text
左悬浮窗：结构窗
├─ 上区：主结构树区
│  ├─ 功能树
│  ├─ 模块树
│  └─ UI 层次树
└─ 下区：辅助导航区
   ├─ 搜索结果
   ├─ 过滤条件
   ├─ 最近访问节点
   ├─ 已确认基准节点
   └─ 异常节点
```

## 9. 右侧悬浮窗：属性 / 探查窗

右侧能力也不固定在主窗体中，而是做成悬浮工具窗。

职责：属性、状态、来源、位置、可信度、关联、问题、决定、变更、备注、日志。

推荐结构：

```text
右悬浮窗：项目探查窗
├─ 上区：当前对象属性区
│  ├─ 基本属性
│  ├─ 状态
│  ├─ 来源位置
│  └─ 可信度
└─ 下区：关联与过程区
   ├─ 关联功能
   ├─ 关联模块
   ├─ 关联 UI
   ├─ 问题
   ├─ 决定
   ├─ 变更
   └─ 备注
```

## 10. 窗口行为标准

所有悬浮窗建议支持：显示/隐藏、置顶/取消置顶、锁定/跟随、记忆位置、记忆大小、记忆上次打开状态、支持多显示器、可折叠局部面板、可使用 Splitter 调整上下区域。

## 11. 信息流标准

```text
用户在左侧结构窗选择对象
    ↓
主窗体中部显示对象主内容
    ↓
右侧探查窗显示对象属性、状态、来源、关联
    ↓
底部信息区显示日志、问题、操作记录
```

职责：左侧选对象，中间看内容，右侧查依据，底部看过程，顶部看全局摘要。

## 12. DeepSpec 中的落地

- 主窗体：工具栏 + 可折叠项目摘要区 + WebView2 主呈现区 + 可折叠底部状态/日志 Tab 区。
- 左悬浮结构窗：候选功能树、模块树、UI 层次树、搜索结果、过滤条件、异常节点。
- 右悬浮探查窗：节点属性、来源文件、来源位置、可信度、关联功能、关联模块、关联 UI、问题、决定、变更、备注。

## 13. 最终标准句

> DeepShell 桌面标准壳：主窗体轻，中间工作；左右悬浮，多区多页；上下折叠，多 Tab 承载。
