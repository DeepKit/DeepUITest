# DeepSpec 接入 DeepShell 的 Provider 方案

## 1. 总体关系

DeepShell 是壳，DeepSpec 是业务产品。

DeepShell 框架层提供主窗体、结构窗、探查窗、顶部摘要区、底部日志区、命令系统、事件总线和布局管理器。DeepSpec 业务层提供项目扫描器、Delphi/VCL 解析器、模块树生成器、UI 层次树生成器、候选功能树生成器、HTML 报告生成器、AI 参考摘要生成器和 Provider 接入层。

原则：DeepShell 管界面壳，DeepSpec 管项目分析。

## 2. DeepSpec 需要实现的 Provider

### TDeepSpecStructureProvider

负责告诉 DeepShell 左侧结构窗里有哪些树、每棵树有哪些节点。

DeepSpec 对应三棵树：

- 模块树；
- UI 层次树；
- 候选功能树。

```pascal
TDeepSpecStructureProvider = class(TInterfacedObject, IShellStructureProvider)
public
  function GetTreeNames: TArray<string>;
  function GetTreeRoot(const ATreeName: string): TObject;
  function GetNodeChildren(ANode: TObject): TArray<TObject>;
  function GetNodeDisplayText(ANode: TObject): string;
end;
```

### TDeepSpecInspectorProvider

负责告诉右侧探查窗当前节点有哪些属性、来源、状态、关联、问题。

示例：用户点中 UI 节点 `BtnOpenFolder`，右侧探查窗显示节点名称、控件类型、Caption、来源文件、父节点、候选功能、关联模块、状态、可信度等。

```pascal
TDeepSpecInspectorProvider = class(TInterfacedObject, IShellInspectorProvider)
public
  function GetProperties(AObject: TObject): TArray<TShellProperty>;
  function GetRelations(AObject: TObject): TArray<TShellRelation>;
  function GetIssues(AObject: TObject): TArray<TShellIssue>;
end;
```

### TDeepSpecMainViewProvider

负责告诉主窗体中间 WebView2 当前对象应该显示哪个 HTML 页面。

| 当前对象 | 主窗体显示 |
|---|---|
| 扫描总览 | `scan-report.html` |
| 模块节点 | `node-detail.html?type=module&id=xxx` |
| UI 节点 | `node-detail.html?type=ui&id=xxx` |
| 功能节点 | `node-detail.html?type=function&id=xxx` |
| 文档文件 | `documents.html` 或文件预览 |
| AI 摘要 | `ai-reference.html` |

树本身不用 HTML；但树节点的详情可以用 HTML 显示在主窗体中。

### TDeepSpecCommandProvider

负责注册 DeepSpec 命令：

- OpenFolder；
- RescanProject；
- ShowStructureWindow；
- ShowInspectorWindow；
- ShowScanReport；
- ShowAIReference；
- ConfirmBaseline；
- CopyNodeForAI；
- OpenSourceFile；
- ExportReport。

### TDeepSpecLogProvider

负责把扫描日志、解析问题、错误信息送到底部信息区。

示例日志：

```text
开始扫描项目：D:\_Progs\DeepSpec
发现 Delphi 工程：DeepSpec.dproj
解析 UMainForm.dfm 成功，发现 42 个控件
解析 UOldForm.dfm 失败：binary dfm 暂不支持
生成 UI 层次树完成
生成模块树完成
候选功能树生成完成
```

## 3. DeepSpec 业务核心类

- `TDeepSpecProject`：项目对象，保存项目路径、项目名称、项目类型、扫描时间、扫描结果、三棵树、HTML 输出目录。
- `TDeepSpecScanner`：项目扫描器，负责递归扫描目录、忽略无关目录、识别文件类型、统计文件数量、发现 Delphi 工程。
- `TDelphiProjectParser`：Delphi 项目解析器，解析 `.dpr`、`.dproj`、识别主窗体、Unit、Form。
- `TPasUnitParser`：Pascal 单元解析器，读取 unit 名、uses、class、form class、方法名、事件处理器。
- `TDFMParser`：DFM 解析器，解析 text dfm，读取 object/inherited、控件名称、控件类型、Caption、Parent 层级、Action。
- `TModuleTreeBuilder`：模块树生成器。
- `TUITreeBuilder`：UI 层次树生成器。
- `TFunctionTreeBuilder`：候选功能树生成器。
- `TDeepSpecHtmlRenderer`：HTML 报告生成器。
- `TDeepSpecAIReferenceBuilder`：AI 参考摘要生成器。

## 4. 核心事件流

### 打开文件夹

```text
MainForm.OpenFolder
  ↓
CommandManager.Execute(OpenFolder)
  ↓
DeepSpecScanner.Scan
  ↓
生成扫描结果
  ↓
EventBus.ProjectScanned
  ↓
TopPanel 更新项目摘要
  ↓
MainView 显示 scan-report.html
  ↓
StructureWindow 加载三棵树
  ↓
BottomPanel 写入扫描日志
```

### 点击 UI 树节点

```text
StructureWindow.SelectNode(BtnOpenFolder)
  ↓
EventBus.ObjectSelected
  ↓
ShellContext 更新为 UINode
  ↓
InspectorProvider.GetProperties
  ↓
InspectorWindow 显示属性
  ↓
MainViewProvider.GetViewForObject
  ↓
MainForm.WebView2 显示 node-detail.html
```

### 确认基准

```text
用户右键节点 / 树：确认基准
  ↓
CommandManager.Execute(ConfirmBaseline)
  ↓
更新节点状态 candidate → confirmed
  ↓
写入 baseline yaml
  ↓
EventBus.BaselineConfirmed
  ↓
树节点图标更新
  ↓
底部日志记录操作
```

## 5. 总结

DeepShell 提供标准桌面壳；DeepSpec 通过 Provider 接入项目扫描、三棵树、节点探查、HTML 报告和 AI 参考摘要。
