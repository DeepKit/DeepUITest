# DeepSpec / 深范 MVP 开发设计定稿包

## 当前最终口径

DeepSpec MVP 是一个 **项目开发文档与结构树读取呈现系统**。

用户把一个 Windows 项目文件夹拖进 DeepSpec，或通过“打开文件夹”选择已有开发目录；DeepSpec 读取其中已有的文档、代码、UI 文件、配置和 AI 规则文件，生成项目扫描报告、软件模块树、UI 层次树、候选功能树，并用 DeepShell 桌面标准壳进行呈现和探查，作为后续人工或 AI 开发、对比、调优和交接的基准。

## MVP 不做

- 不做主流程式 6 问 / 12 问需求采集；
- 不要求用户粘贴 AI 对话；
- 不接管用户如何与 AI 沟通；
- 不直接调用 Codex / Claude Code / OpenCode；
- 不做 AI Agent 开发治理；
- 不做 CLI 调度；
- 不自动修改代码；
- 不用一个巨大 HTML 报告呈现全部内容；
- 不用 HTML 渲染三棵核心树。

## MVP 要做

1. 拖入项目文件夹 / 打开项目文件夹；
2. 扫描项目目录；
3. 识别文档、代码、UI、配置、AI 规则文件；
4. 优先识别 Delphi/VCL 项目；
5. 解析 `.dpr / .dproj / .pas / .dfm`；
6. 生成项目扫描报告；
7. 生成软件模块树；
8. 生成 UI 层次树；
9. 生成候选功能树；
10. 用 Delphi/VCL 原生树控件呈现三棵树；
11. 用 WebView2 / HTML 呈现扫描报告、详情页、说明页和 AI 参考摘要；
12. 允许用户确认树或节点为基准；
13. 导出 AI 参考摘要，但不调用 AI。

## 核心口号

- 拖入项目，看清结构。
- 把已有项目读成三棵树。
- 树用 VCL，文档用 HTML。
- 开发前先定三棵基准树，AI 才不会乱长。
