# DeepSpec 界面原则：树用 VCL，文档用 HTML

## 一、核心原则

# **树用 VCL，文档用 HTML。**

即：

- 功能树、模块树、UI 层次树，必须用 Delphi/VCL 原生控件呈现和操作；
- 扫描报告、文档详情、AI 参考摘要、说明页等文档型内容，用 WebView2 / HTML 呈现。

---

## 二、为什么三棵树不能用 HTML 渲染

三棵树不是静态报告，而是核心交互对象。

用户需要对树节点进行：

- 展开；
- 折叠；
- 选择；
- 定位源文件；
- 右键操作；
- 标记为基准；
- 标记为候选；
- 标记为废弃；
- 查看来源；
- 关联功能 / 模块 / UI；
- 调整层级；
- 搜索；
- 过滤；
- 高亮变化。

这些能力更适合用 Delphi/VCL 原生树控件实现。

---

## 三、推荐控件

### MVP 原型

可以使用：

```text
TTreeView
```

### 长期版本

建议使用：

```text
VirtualStringTree / TVirtualStringTree
```

原因：

- 大量节点性能更好；
- 可做树表；
- 可显示多列；
- 可自定义图标、状态、来源、可信度；
- 方便扩展过滤、搜索、高亮。

---

## 四、主界面建议

```text
+------------------------------------------------------------------+
| 打开文件夹 | 重新扫描 | 确认基准 | 导出报告 | AI参考 | 设置      |
+------------------+------------------------------+----------------+
| 左侧项目导航      | 中间结构树区                  | 右侧详情区       |
|                  |                              |                |
| 扫描总览          | [功能树] [模块树] [UI层次树]  | 节点属性         |
| 文档文件          |                              | 来源文件         |
| 代码文件          |  VCL 原生树控件               | 关联节点         |
| UI 文件           |                              | WebView2详情     |
| 配置文件          |                              |                |
| AI规则文件        |                              |                |
+------------------+------------------------------+----------------+
| 状态栏：项目路径 / 文件数 / 当前树 / 当前节点 / 状态 / 来源       |
+------------------------------------------------------------------+
```

---

## 五、HTML 负责什么

HTML / WebView2 负责：

- 扫描报告；
- 文档清单；
- 代码文件清单；
- UI 文件清单；
- 配置文件清单；
- AI 规则文件清单；
- AI 参考摘要；
- 当前节点详情；
- 决定记录；
- 变更记录；
- 可导出、可打印、可外部浏览器打开的说明页。

---

## 六、小 HTML 文件原则

DeepSpec 不生成一个巨大的单页 HTML。

应生成多个小 HTML：

```text
index.html
scan-report.html
documents.html
code-files.html
ui-files.html
config-files.html
ai-rules.html
ai-reference.html
node-detail.html
decision-log.html
change-log.html
```

其中三棵树不主要用 HTML 呈现，而是由 VCL 原生树控件呈现。

---

## 七、总结

> **树是操作对象，HTML 是阅读对象。**
