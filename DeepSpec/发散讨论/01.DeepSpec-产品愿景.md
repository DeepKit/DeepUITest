# DeepSpec 深范｜产品愿景

## 1. 产品名称

**DeepSpec｜深范**

中文名：**深范**

含义：

- **规范**：软件开发文件必须有结构、有规则、有检查。
- **范本**：每类开发文档都有标准模板。
- **范式**：形成 AI Coding 时代的软件开发规格治理方法。
- **示范**：给人类、AI、团队交接提供正确写法。

---

## 2. 一句话定位

> **DeepSpec 深范：AI Coding 时代的旁路规格治理系统。**

更完整的说法：

> **在 IDE、CLI、Codex、Claude Code 等主线开发工具旁边，守住软件开发的规格、证据、决策、测试、变更和交接链。**

---

## 3. 它不是什么

DeepSpec 不是：

- 普通文档管理工具；
- Markdown 美化工具；
- 知识库；
- IDE；
- 代码编辑器；
- AI 聊天框；
- Codex / Claude Code / Cursor 的替代品；
- 项目管理软件；
- 单纯的 HTML 浏览器。

---

## 4. 它是什么

DeepSpec 是：

> **面向软件开发过程的规格治理、文档规范、变更审查与交接辅助系统。**

它负责把开发过程中的以下内容结构化：

- 产品意图；
- 用户场景；
- 功能树；
- 界面说明；
- 状态机；
- 技术方案；
- 接口定义；
- 讨论记录；
- 变更日志；
- AI 编程前的 Context Pack；
- AI 编程后的 Review Pack；
- 下一轮开发的 Handoff Pack。

---

## 5. 核心问题

AI 编程工具越来越强，但项目也越来越容易失控：

1. AI 改了很多代码，但人不知道影响了哪些规格。
2. 用户在 Codex / Claude Code 里聊完，回到项目后没有留下工程证据。
3. 功能实现了，但产品愿景、功能树、接口定义、测试文档没有同步更新。
4. 每次新开 AI 会话，都要重新解释项目背景。
5. 老项目缺少交接文档，AI 也读不懂历史决策。
6. 文档写了很多，但没有状态、没有检查、没有冻结、没有追踪。
7. 决策理由散落在聊天记录里，过几天就找不到。

DeepSpec 要解决的不是“帮你写文档”，而是：

> **防止 AI 编程把项目越改越乱。**

---

## 6. 核心价值

DeepSpec 要让软件开发文件具备五个“可”：

| 目标 | 含义 |
|---|---|
| 可读 | 人类打开就能看懂，有结构、有层次、有重点 |
| 可查 | AI 和程序能结构化解析、搜索、关联、追溯 |
| 可执行 | 开发者看完能知道下一步该写什么代码 |
| 可测试 | 每个功能、状态、接口都有验收和测试口 |
| 可交接 | 换人、换 AI 会话、换开发阶段后仍能继续 |

---

## 7. 产品边界

DeepSpec 的工作边界是：

```text
开发前：生成 Context Pack，喂给外部 AI / IDE / CLI
开发中：不接管主线，只旁路观察文件、Git、测试和日志
开发后：生成 Review Pack，发现规格漂移、缺失文档、待确认决定
交接时：生成 Handoff Pack，让下一轮人类或 AI 能接上
```

---

## 8. 与外部 AI 工具的关系

DeepSpec 不替代：

- Codex；
- Claude Code；
- Cursor；
- GitHub Copilot；
- JetBrains AI；
- VS Code；
- Delphi IDE；
- 命令行工具。

DeepSpec 的定位是：

> **外部 AI 负责做事，DeepSpec 负责把做事留下的工程后果接住。**

---

## 9. 第一目标用户

### 9.1 准备规范化开发软件的人

尤其是：

- 独立开发者；
- 多项目开发者；
- Delphi / VCL 老项目维护者；
- AI Coding 重度使用者；
- 需要与 AI 长期协作的人；
- 希望项目能交接、复盘、持续演进的人。

### 9.2 旁路使用场景

用户仍然在 IDE / CLI / Codex / Claude Code 里开发。  
DeepSpec 在旁边提供：

- 上下文包；
- 规格检查；
- 变更影响分析；
- 决策沉淀；
- 文档更新建议；
- 交接卡。

---

## 10. 第一版技术路线

- Delphi + VCL 做主程序；
- 左侧文档树；
- 右侧 WebView2 / TEdgeBrowser 审阅 HTML；
- YAML 作为事实源；
- HTML 作为人类审阅层；
- Spec Inspector 悬浮面板显示属性、问题、决定；
- Git Diff / 文件变化 / 测试输出作为旁路证据；
- 后续可接 SQLite 作为缓存和索引。

---

## 11. 产品口号

> **AI 在主线写代码，DeepSpec 在旁路守规范。**

> **不接管 AI 编程，只接住 AI 编程留下的工程后果。**

> **让 AI 能读懂项目，让人能审查变更，让团队能接得住工程。**
