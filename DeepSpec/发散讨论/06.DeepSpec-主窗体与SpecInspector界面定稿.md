# DeepSpec 主窗体与 Spec Inspector 界面定稿

## 一、主窗体定位

主窗体是：

> **文档导航与可视化审阅工作台。**

它只做：

- 项目导航；
- 文档树；
- HTML 审阅；
- 基础操作；
- 状态显示。

不把属性、问题、决定挤在主窗体上。

---

## 二、主窗体布局

```text
+------------------------------------------------------+
| 工具栏：新建 / 打开 / 生成 / 检查 / 导出 / Inspector |
+-------------------+----------------------------------+
| 左侧文档树         | 右侧 WebView2 HTML 审阅区          |
|                   |                                  |
| 产品层             |                                  |
|  - 产品愿景        |                                  |
|  - 用户画像        |                                  |
|  - 功能树          |                                  |
| 工程层             |                                  |
|  - 界面展示        |                                  |
|  - 状态机          |                                  |
|  - 技术方案        |                                  |
|  - 接口定义        |                                  |
| 治理层             |                                  |
|  - 讨论记录        |                                  |
|  - 变更日志        |                                  |
+-------------------+----------------------------------+
| 状态栏：当前项目 / 当前文档 / 状态 / 红绿灯           |
+------------------------------------------------------+
```

---

## 三、Spec Inspector 定位

Spec Inspector 是当前文档的：

```text
属性检查器
问题检查器
决定检查器
```

三个页签：

```text
属性 | 问题 | 决定
```

---

## 四、属性页

回答：

> 这个文档是谁？在哪里？和谁有关？

显示：

- Spec ID；
- 标题；
- 类型；
- 状态；
- 版本；
- YAML 路径；
- HTML 路径；
- 当前 Hash；
- 冻结 Hash；
- 上游文档；
- 下游文档；
- 关联测试；
- 关联决定。

---

## 五、问题页

回答：

> 这个文档缺什么？为什么不能冻结？

显示：

- 总体灯色；
- 检查分数；
- 红灯问题；
- 黄灯问题；
- 蓝灯建议；
- 已忽略问题。

问题操作：

- 定位；
- 转为决定；
- 忽略；
- 复制。

---

## 六、决定页

回答：

> 这件事为什么这样定？

显示：

- 已确认决定；
- 待确认决定；
- 已否决方案；
- 已废弃决定。

每条决定包含：

- 议题；
- 选项；
- 最终选择；
- 理由；
- 影响范围；
- 确认人；
- 确认时间；
- 关联文档。

---

## 七、悬浮模式

Spec Inspector 有两种模式：

### 跟随模式

主窗体选中什么，Inspector 显示什么。

### 锁定模式

Inspector 固定在某个文档，主窗体可以切换其他文档进行对照。

---

## 八、交互原则

1. 主窗体保持清爽；
2. Inspector 需要时浮出；
3. 所有操作走命令系统；
4. 问题可以转为决定；
5. 决定可以写入讨论记录；
6. 红灯不能冻结；
7. HTML 只触发意图，不直接改文件。

---

## 九、产品辨识度

普通文档工具只有内容。

DeepSpec 的每份文档都有：

```text
身份
质量
决策链
```

这是 DeepSpec 的核心辨识度。
