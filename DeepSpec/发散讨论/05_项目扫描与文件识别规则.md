# DeepSpec 项目扫描与文件识别规则

## 一、扫描入口

用户通过以下方式打开项目：

1. 将项目文件夹拖入 DeepSpec；
2. 点击“打开文件夹”选择已有项目目录。

---

## 二、扫描时应忽略的目录

默认忽略：

```text
.git
.svn
.hg
node_modules
bin
obj
__history
__pycache__
dist
build
.cache
.tmp
```

可后续加入用户自定义忽略规则。

---

## 四、扫描总览应显示

扫描后生成：

```text
项目路径
项目类型
扫描时间
文件总数
主要语言
是否发现 Delphi 工程
是否发现 DFM
是否发现 AI 规则文件
```

文件统计：

```text
文档文件数量
代码文件数量
UI 文件数量
配置文件数量
AI 规则文件数量
未知文件数量
```

---

## 五、项目类型识别

MVP 优先识别：

```text
Delphi VCL 项目
Delphi FMX 项目
未知项目
```

后续扩展：

```text
前端 Web 项目
Python 项目
C# 项目
Go 项目
Java 项目
混合项目
```

---

## 六、扫描输出

扫描结果保存为：

```text
.deepspec/scan-report.yaml
.deepspec/html/scan-report.html
```

扫描报告是 HTML，但三棵树由 VCL 原生树控件呈现。
