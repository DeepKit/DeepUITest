# 第二批开发：Delphi/VCL 解析 + UI 层次树 + 模块树

## 目标

让 DeepSpec 从“看到了项目文件”升级为“读出了 Delphi/VCL 项目结构”。

完成后应能识别 `.dpr / .dproj / .pas / .dfm`，识别 Form / Frame / DataModule，解析 text DFM，生成 UI 层次树与模块树，并在结构窗显示真实节点。

## Delphi/VCL 中间模型

### TDelphiProjectModel

保存 ProjectPath、DprFiles、DprojFiles、Units、Forms。

### TDelphiUnitModel

保存 UnitName、FilePath、RelativePath、UsesUnits、Classes、Methods、IsFormUnit、FormClassName、DfmFilePath。

### TDelphiFormModel

保存 FormName、FormClassName、PasFilePath、DfmFilePath、RootControl。

### TUIControlModel

保存 Id、Name、ClassName、Caption、Parent、Children、SourceFile、SourceLine、Align、Left、Top、Width、Height、ActionName。

## `.pas` 解析策略

轻量文本解析：

- 读取 unit 名；
- 读取 uses；
- 识别 `TForm / TFrame / TDataModule`；
- 记录事件处理器，如 `BtnOpenFolderClick`、`actExportExecute`。

## `.dfm` 解析策略

MVP 先支持 text DFM。遇到 binary DFM 记录问题，不崩溃。

核心规则：

```text
遇到 object / inherited → 创建控件节点并入栈
遇到 end → 当前节点出栈
属性行 key = value → 写入当前节点属性
```

优先读取属性：

```text
Caption
Align
Left
Top
Width
Height
ClientWidth
ClientHeight
Action
Name
TabOrder
```

## UI 层次树

节点显示格式：

```text
控件名 : 控件类型 [Caption]
```

示例：

```text
TMainForm
├─ TopPanel : TPanel
│  ├─ BtnOpenFolder : TButton [打开文件夹]
│  └─ BtnExport : TButton [导出报告]
├─ MainBrowser : TEdgeBrowser
└─ StatusBar : TStatusBar
```

## 模块树

先按目录生成，再挂 `.pas` 文件。单元类型标记：

```text
FormUnit
DataModule
Frame
Service
Model
Unknown
```

## Provider 第二批实现

- `TDeepSpecStructureProvider` 返回模块树和 UI 层次树；
- `TDeepSpecInspectorProvider` 显示 UI 节点和模块节点属性；
- `TDeepSpecMainViewProvider` 让主浏览区显示 `node-detail.html`。
