# DeepSpec 外部 AI 上下文包导出规范

## 一、定位

MVP 不直接调用外部 AI，也不接管 Codex / Claude Code / OpenCode / Cursor。

MVP 只生成：

> **外部 AI 可使用的上下文材料。**

---

## 二、为什么 MVP 必须支持上下文导出

如果 DeepSpec 只生成 HTML 文档，它容易被认为是普通文档工具。

如果 DeepSpec 能生成外部 AI 可用材料，它就从第一版开始服务 AI 编程。

---

## 三、MVP 可导出内容

MVP 可以导出：

1. Context Pack；
2. AGENTS.md 草稿；
3. CLAUDE.md 草稿；
4. Cursor Rules 草稿；
5. Handoff 草稿；
6. 任务说明草稿。

---

## 四、Context Pack 内容

一个 Context Pack 应包含：

```text
项目是什么；
当前目标是什么；
相关规格有哪些；
已确认决定有哪些；
禁止做什么；
允许修改什么；
验收标准是什么；
完成后必须汇报什么。
```

---

## 五、AGENTS.md 草稿

AGENTS.md 草稿应包含：

- 项目概述；
- 目录结构；
- 开发规则；
- 禁止事项；
- 测试方式；
- 完成定义；
- AI 行为边界。

---

## 六、CLAUDE.md 草稿

CLAUDE.md 草稿应包含：

- 项目背景；
- 当前开发阶段；
- 已确认决定；
- 代码与文档边界；
- 推荐工作方式；
- 不确定时如何处理。

---

## 七、Cursor Rules 草稿

Cursor Rules 草稿应包含：

- 编码规则；
- 文件修改边界；
- 项目结构约束；
- 测试要求；
- 不要推翻的决定；
- 不要自动执行的事项。

---

## 八、Handoff 草稿

Handoff 应包含：

- 当前项目状态；
- 已完成文档；
- 未解决问题；
- 已确认决定；
- 下一步任务；
- 外部 AI 应先读取哪些文档；
- 禁止越界事项。

---

## 九、MVP 边界

MVP 只生成这些材料，不负责：

- 调用 AI；
- 读取 AI 对话；
- 监控 AI 执行；
- 扫描 Git Diff；
- 生成完整 Review Pack。

这些属于阶段二。
