# DeepSpec 深范：近期讨论总览

## 记录目的

本文件包记录近期关于 DeepSpec / 深范 的产品方向讨论，重点保存已经收束后的设计结论，便于后续继续讨论、开发或新开会话交接。

---

## 一、近期最重要的纠偏

我们曾经讨论过若干方向，包括：

- 可视化需求文档生成系统；
- 6 问 / 12 问需求采集向导；
- AI Agent 开发旁路治理；
- 未来调用 Codex / Claude Code / OpenCode 等 CLI；
- 开发文档记录与呈现系统。

最终，第一版 MVP 被进一步收束为：

# **项目开发文档与结构树读取呈现系统**

也就是：

> **用户把一个 Windows 项目文件夹拖进 DeepSpec，或者用“打开文件夹”选择已有开发目录；DeepSpec 读取该目录中已有的文档、代码、UI 文件、配置和 AI 规则文件，生成项目扫描报告、软件模块树、UI 层次树和候选功能树，并以 Delphi/VCL 原生控件与 WebView2 结合的方式呈现，作为后续人工或 AI 开发、对比、调优和交接的基准。**

---

## 二、当前第一版不做什么

MVP 第一版不做：

- 不做主流程式 6 问 / 12 问需求采集；
- 不要求用户粘贴 AI 对话；
- 不接管用户如何与 AI 沟通；
- 不直接调用 Codex / Claude Code / OpenCode；
- 不做 AI Agent 开发治理；
- 不做 CLI 调度；
- 不自动修改代码；
- 不以一个巨大 HTML 报告为主；
- 不用 HTML 渲染三棵核心树。

---

## 三、当前第一版要做什么

MVP 第一版要做：

1. 拖入项目文件夹 / 打开项目文件夹；
2. 扫描项目目录；
3. 识别文档、代码、UI、配置、AI 规则文件；
4. 优先识别 Delphi/VCL 项目；
5. 解析 `.dpr / .dproj / .pas / .dfm`；
6. 生成项目扫描报告；
7. 生成软件模块树；
8. 生成 UI 层次树；
9. 生成候选功能树；
10. 使用 Delphi/VCL 原生树控件呈现三棵树；
11. 使用 WebView2 / HTML 呈现扫描报告、详情页、说明页和 AI 参考摘要；
12. 允许用户确认树或节点为基准；
13. 导出 AI 参考摘要，但不调用 AI。

---

## 四、最终口号候选

> **拖入项目，看清结构。**

> **把已有项目读成三棵树。**

> **树用 VCL，文档用 HTML。**

> **开发前先定三棵基准树，AI 才不会乱长。**

---

## 五、当前产品哲学

> **先定形，再生成；先对齐，再开发；先留痕，再迭代。**

在当前 MVP 中，这句话具体体现为：

> **先从已有项目目录中读取真实文档和代码，再形成模块树、UI 层次树和候选功能树，供后续开发与 AI 修改时对齐。**
