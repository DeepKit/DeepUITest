# DeepSpec 工程目录与单元划分

## 1. 总体原则

DeepSpec 工程应分成两层：

```text
DeepShell/   通用界面壳，可复用
DeepSpec/    本产品业务逻辑
```

原则：

> Shell 不懂业务，业务不绑窗体，Provider 负责接入。

## 3. 分层说明

- `shell/`：通用 Shell 层，只知道上下文、命令、事件、布局、Provider、窗口状态。
- `shell_forms/`：通用窗体层，包括主窗体、结构窗、探查窗、顶部面板、底部面板。
- `deepspec_core/`：业务模型层，定义项目、文件索引、扫描结果、树节点、树模型、节点状态、文件类型。
- `deepspec_scan/`：扫描层，负责扫描目录、分类文件、识别项目类型、生成扫描结果。
- `deepspec_delphi/`：Delphi/VCL 解析层，识别 `.dpr`、读取 `.dproj`、解析 `.pas` 和 `.dfm`。
- `deepspec_trees/`：三棵树生成层，生成模块树、UI 层次树、候选功能树。
- `deepspec_render/`：HTML / Markdown 生成层，生成扫描报告、文件清单、AI 参考摘要、节点详情。
- `deepspec_providers/`：DeepSpec 与 DeepShell 的桥。

## 4. 开发批次

### 第一批

目标：打开文件夹、扫描目录、分类文件、生成 scan-report.html、主窗体 WebView2 显示报告、结构窗和探查窗打开但可为空。

### 第二批

目标：识别 Delphi 项目、解析 `.pas / .dfm`、生成 UI 层次树和模块树、结构窗显示真实树、探查窗显示节点属性。

### 第三批

目标：生成候选功能树、建立简单关联、确认基准、生成 AI 参考摘要、复制节点说明给外部 AI。

## 5. 关键工程原则

> 先让数据跑通，再美化界面。

优先顺序：

1. 扫描能跑；
2. 文件能分类；
3. DFM 能解析；
4. UI 树能出来；
5. 模块树能出来；
6. WebView2 能显示报告；
7. 树窗能显示节点；
8. 探查窗能显示属性；
9. 再考虑图标、颜色、布局美化。
