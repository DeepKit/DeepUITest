# 第六批开发：Delphi/VCL 解析策略定稿

## 目标

第六批定稿 DeepSpec MVP 的 Delphi/VCL 解析策略。

目标不是写完整 Delphi 编译器，而是做一个够用、稳健、不会崩、能生成三棵树基础数据的轻量解析层。

## 总原则

- 不追求编译级准确；
- 所有解析结果都有来源；
- 解析失败也要成为结果；
- 轻量、稳健、可追溯；
- 先读出结构，再逐步提高理解深度。

## `.dpr` 解析

提取：

```text
program 名
uses 引用的 pas 文件
Form 别名
Application.CreateForm 中的主窗体
```

作用：识别主窗体、关联 pas 和 dfm、帮助 UI 树排序。

## `.dproj` 解析

`.dproj` 是 XML，第一版只轻量读取：

```text
项目名
项目 GUID
目标平台
配置
MainSource
包含的文件项
```

重点找 MainSource 和 DCCReference。不要过度依赖 `.dproj`，因为老项目可能不完整。

## `.pas` 解析

轻量文本解析：

- 识别 unit 名；
- 识别 uses；
- 识别类；
- `TForm` → FormUnit；
- `TFrame` → FrameUnit；
- `TDataModule` → DataModule；
- 识别事件处理器；
- 根据同名规则关联 DFM。

## `.dfm` 解析

MVP 优先支持 text DFM。

支持：

```text
object
inherited
inline
end
属性 key = value
```

算法：

```text
遇到 object/inherited/inline
  创建控件节点
  如果栈不空，挂到栈顶节点 children
  当前节点入栈

遇到 end
  当前节点出栈
```

优先提取属性：

```text
Name
ClassName
Caption
Hint
Action
Align
Left
Top
Width
Height
ClientWidth
ClientHeight
TabOrder
Visible
Enabled
```

## Caption 解码

优先处理普通字符串、带 `&` 快捷键符号的字符串、简单 `#数字` 编码串。遇到复杂编码，保留原始值并记录问题。

## Action 关联

如果控件有 `Action = actOpenFolder`，UI 节点记录 action。后续候选功能树从 ActionList 提取 Caption。

## Menu 解析

菜单也是候选功能树的重要来源。UI 树保留菜单层级。

## Binary DFM

MVP 不完整支持 binary DFM。遇到 binary DFM：

- 不崩溃；
- 记录 warning；
- 提示用户可在 Delphi 中保存为 text DFM。

## Inherited DFM

第一版处理策略：

- 当成 object 解析；
- 标记 inherited = true；
- 不尝试自动合并父窗体 DFM。

## UI 层次树生成

节点显示格式：

```text
控件名 : 控件类型 [Caption]
```

多个窗体按 `.dpr` 中 Application.CreateForm 顺序、文件名、窗体名排序。

## 模块树生成

模块树第一版以目录为主，目录下挂 `.pas` 文件。

Unit 类型标记：

```text
FormUnit
FrameUnit
DataModule
ClassUnit
ModelUnit
ServiceUnit
Unknown
```

## 解析问题分级

- Info：发现项目、发现 DFM、解析完成；
- Warning：Binary DFM、Form 单元未找到 DFM、Caption 解码不完整；
- Error：DFM object/end 不匹配、文件读取失败、编码读取失败；
- Fatal：尽量避免，除非项目目录无法访问。

## 探查窗显示规则

点击 UI 节点显示名称、控件类型、Caption、Hint、Action、Align、位置尺寸、来源 DFM、来源行号、父节点、子节点数量、是否 inherited、解析状态、相关问题。

点击模块节点显示模块名、目录路径、文件数量、Pas 单元列表、Unit 类型分布、是否包含 Form/DataModule/DFM、相关问题。

## 实现优先级

P0：`.dpr` 轻量解析、`.pas` unit/class/form 识别、text DFM 栈解析、UI 控件层级生成、模块树按目录生成、探查窗显示 UI 节点属性、解析日志与问题记录。

P1：Caption 简单解码、Action 识别、MenuItem 层级提取、DataModule / Frame 识别、DFM inherited 标记。

P2：Binary DFM、复杂 inherited 合并、完整 uses 依赖图、调用链分析、完整 Pascal AST、UI 截图对比。
