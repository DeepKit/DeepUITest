# DeepSpec MVP 数据结构与文件目录

## 一、推荐目录结构

当用户允许在项目中生成 DeepSpec 工作目录时：

```text
项目目录/
  .deepspec/
    project.yaml
    scan-report.yaml

    trees/
      function-tree.yaml
      module-tree.yaml
      ui-tree.yaml

    baselines/
      function-tree.baseline.yaml
      module-tree.baseline.yaml
      ui-tree.baseline.yaml

    html/
      index.html
      scan-report.html
      documents.html
      code-files.html
      ui-files.html
      config-files.html
      ai-rules.html
      ai-reference.html
      node-detail.html
      decision-log.html
      change-log.html

    logs/
      scan-log.txt
```

也可以支持保存到 DeepSpec 本地工作区，而不写入用户项目。

## 七、基准文件

当用户确认当前树为基准时，生成：

```text
function-tree.baseline.yaml
module-tree.baseline.yaml
ui-tree.baseline.yaml
```

MVP 只需要支持确认基准，不需要做完整漂移对比。

---

## 八、HTML 文件原则

HTML 文件只负责报告、详情、摘要，不负责三棵树主呈现。

三棵树由 VCL 原生树控件读取 YAML / 内存对象呈现。
