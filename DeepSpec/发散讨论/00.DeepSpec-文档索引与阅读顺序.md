## 2. 当前冻结结论

### 产品名称

**DeepSpec｜深范**

### 一句话定位

**AI Coding 时代的旁路规格治理系统。**

### 更完整定位

DeepSpec 不接管 IDE、CLI、Codex、Claude Code 等主线开发工具，而是在旁路守住软件开发的规格、证据、决策、测试、变更和交接链。

### 核心技术路线

- Delphi + VCL
- WebView2 / TEdgeBrowser
- YAML 作为机器事实源
- HTML 作为人类审阅层
- Git Diff / 文件变化 / 测试输出作为旁路证据
- Spec Inspector 悬浮面板负责属性、问题、决定
- Context Pack 给外部 AI 工具使用
- Review Pack 用于 AI 编程后的规范审查
