# 第一批开发：DeepShell 壳 + 项目扫描 + 文件分类 + 扫描报告

## 目标

跑通最小链路：

```text
打开文件夹 → 创建 TDeepSpecProject → 扫描文件 → 分类文件 → 生成 TDeepSpecScanResult → 生成 scan-report.html → WebView2 显示 → 顶部摘要刷新 → 底部日志显示
```

## 完成标准

- 能打开文件夹；
- 能统计文件；
- 能分类文件；
- 能识别 `.dpr / .dproj / .pas / .dfm`；
- 能生成 `scan-report.html`；
- 能在 WebView2 显示报告；
- 能在底部看到扫描日志；
- 结构树窗能打开但可先显示空树；
- 探查窗能打开但可先显示项目基本信息。

## 核心单元

### UDeepShellTypes.pas

定义事件类型、日志级别、视图类型和命令 ID。

### UDeepShellContext.pas

保存当前项目、当前视图、当前对象。

### UDeepShellEventBus.pas

支持 ProjectOpened、ScanStarted、ScanFinished、ViewChanged、LogAdded 等事件。

### UDeepShellCommandManager.pas

统一执行 OpenFolder、RescanProject、ShowStructureWindow、ShowInspectorWindow、ShowScanReport 等命令。

### UDeepSpecProject.pas

保存 ProjectPath、ProjectName、ProjectType、DeepSpecDir、HtmlDir、LastScanTime、ScanResult。

### UDeepSpecScanResult.pas

保存文件总数、文档数、代码数、UI 文件数、配置数、AI 规则文件数、未知文件数，以及 DprFiles、DprojFiles、PasFiles、DfmFiles。

### UFileClassifier.pas

分类规则：

```text
.md .txt .html .htm → Document
.pas .dpr .dproj → Code
.dfm .fmx → UI
.ini .json .yaml .yml .config → Config
AGENTS.md CLAUDE.md opencode.json .cursor/rules → AIRule
.png .jpg .svg .ico .res .rc → Resource
```

### UDeepSpecScanner.pas

递归扫描目录，忽略 `.git / bin / obj / __history / node_modules` 等目录，调用 FileClassifier 分类并生成 ScanResult。

### UScanReportBuilder.pas

生成 `scan-report.html`。

## 主窗体控件

- ToolBar：打开文件夹、重新扫描、结构窗、探查窗、扫描报告；
- TopPanel：项目路径、项目类型、文件统计、折叠按钮；
- WebView2：MainBrowser；
- BottomPanel：状态、日志、问题；
- StatusBar。

## 第一批不要做

不解析 DFM，不解析 Pas 类和方法，不生成真实模块树，不生成真实 UI 树，不生成候选功能树，不确认基准，不生成 AI 参考摘要。

## 结论

第一批不求聪明，只求链路通：

> 文件夹进来，扫描结果出来，报告显示出来。
