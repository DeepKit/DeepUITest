# DeepSpec 后续讨论清单

## 一、已经定下来的关键原则

1. MVP 是项目目录读取与结构树呈现系统；
2. 用户通过拖入文件夹或打开文件夹使用；
3. 不以问答、粘贴、AI 聊天为主流程；
4. 优先支持 Delphi/VCL；
5. 重点识别 `.pas / .dfm / .dpr / .dproj`；
6. 生成三棵树：模块树、UI 层次树、候选功能树；
7. 三棵树用 VCL 原生树控件呈现；
8. HTML / WebView2 只用于报告、详情、摘要；
9. HTML 应拆分为多个小文件；
10. 可确认树或节点为基准；
11. 可导出 AI 参考摘要；
12. 不调用 AI，不调度 CLI。

---

## 二、下一轮需要重点讨论

### 1. 主窗体具体布局

需要确定：

- 左侧项目导航；
- 中间三棵树区域；
- 右侧详情区；
- 工具栏按钮；
- 状态栏字段。

### 2. 三棵树数据结构

需要定：

- 功能树节点字段；
- 模块树节点字段；
- UI 树节点字段；
- 节点状态；
- 节点来源；
- 节点可信度。

### 3. Delphi DFM 解析策略

需要讨论：

- 如何解析 text DFM；
- 如何处理 binary DFM；
- 如何处理 inherited；
- 如何提取 Caption；
- 如何识别容器控件；
- 如何生成 UI 层次树。

### 4. 模块树生成策略

需要讨论：

- 按目录生成；
- 按 Unit 生成；
- 按类生成；
- 按 uses 关系生成；
- 是否识别窗体肥胖风险。

### 5. 候选功能树生成策略

需要讨论：

- 从 Caption 提取；
- 从 Action 提取；
- 从菜单提取；
- 从 Markdown 提取；
- 如何打可信度分；
- 如何让用户确认。

### 6. AI 参考摘要格式

需要定：

- 项目类型；
- 主要模块；
- UI 结构；
- 候选功能；
- 禁止偏离事项；
- 给外部 AI 的使用说明。

### 7. 基准确认机制

需要定：

- 确认整棵树；
- 确认单个节点；
- 保存 baseline；
- 后续如何比较。
