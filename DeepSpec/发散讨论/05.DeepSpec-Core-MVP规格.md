# DeepSpec Core｜MVP 规格

## 1. MVP 定义

DeepSpec Core MVP 是：

> **一个基于 Delphi VCL + WebView2 的本地软件开发规格治理控制台。**

它以 YAML 为事实源，以 HTML 为人类审阅层，以状态机和红绿灯机制管理文档质量，以旁路扫描方式辅助外部 AI / IDE / CLI 开发后的规格治理。

---

## 2. MVP 不做什么

第一版不做：

- FMX；
- 跨平台；
- 多人协作；
- 云同步；
- 权限系统；
- PDF 导出；
- CI/CD 深度集成；
- GitHub/GitLab API 深度集成；
- 内置 AI Chat；
- 自动改代码；
- 在线富文本编辑器；
- 复杂图表编辑；
- 多窗口复杂 Docking；
- 完整 Delphi 代码分析器。

---

## 3. MVP 必须完成的最小闭环

```text
打开项目
→ 扫描九类文档
→ 左树导航
→ 右侧 HTML 审阅
→ YAML 生成 HTML
→ Schema 检查
→ 红绿灯显示
→ Spec Inspector 查看属性/问题/决定
→ 生成 Context Pack
→ 扫描 Git Diff / 文件变化
→ 生成 Review Pack
→ 生成 Handoff Pack
```

---

## 4. MVP 功能清单

### 4.1 项目打开

- 打开一个 DeepSpec 项目目录；
- 读取 `deepspec.project.yaml`；
- 显示项目名称、路径、版本；
- 记住最近打开项目。

### 4.2 文档扫描

扫描：

```text
specs/*.yaml
html/*.html
```

识别：

- Spec ID；
- 标题；
- 类型；
- 状态；
- 对应 YAML；
- 对应 HTML。

### 4.3 左侧文档树

显示九类文档：

```text
01 产品愿景
02 用户画像
03 功能树
04 界面展示
05 状态机
06 技术方案
07 接口定义
08 讨论记录
09 变更日志
```

每个节点显示红绿灯状态。

### 4.4 右侧 WebView2 审阅区

- 加载对应 HTML；
- HTML 不存在时显示空状态页；
- 支持重新生成后刷新；
- 支持从 HTML 按钮发消息给 VCL。

### 4.5 YAML → HTML

- 读取 YAML；
- 使用模板生成 HTML；
- 更新 `html/` 目录；
- 刷新 WebView2。

### 4.6 Schema 检查

第一版做基础必填项检查。

例如：

- 产品愿景缺 `one_sentence`：红灯；
- 功能树缺 `acceptance_criteria`：黄灯或红灯；
- 技术方案缺 `risks`：黄灯；
- 接口定义缺文件接口：红灯。

### 4.7 红绿灯

| 灯色 | 含义 |
|---|---|
| 绿灯 | 可冻结 |
| 黄灯 | 有缺项，但可继续 |
| 红灯 | 阻塞，不能冻结 |
| 灰灯 | 未开始 |
| 蓝灯 | AI 建议待确认 |
| 紫灯 | 变更中 |
| 黑灯 | 冲突或异常修改 |

### 4.8 Spec Inspector

悬浮面板，包含：

```text
属性｜问题｜决定
```

### 4.9 Context Pack

基于当前任务和相关规格生成给外部 AI 使用的上下文包。

### 4.10 Trace 扫描

第一版支持：

- 文件修改时间对比；
- Git status；
- Git diff --stat；
- 用户手动导入测试日志。

### 4.11 Review Pack

生成 HTML 审查包：

- 变更摘要；
- 修改文件；
- 影响规格；
- 待确认问题；
- 建议决定；
- 建议测试；
- 建议变更日志。

### 4.12 Handoff Pack

生成下一轮交接卡：

- 当前状态；
- 已确认决定；
- 未解决问题；
- 下一步任务；
- 下一轮 AI 应读文件；
- 禁止推翻事项。

---

## 7. MVP 开发顺序

1. VCL 主窗体；
2. WebView2 加载本地 HTML；
3. 项目目录扫描；
4. YAML 读取；
5. 左侧文档树；
6. Spec Inspector 空窗体；
7. 属性页；
8. Schema 检查；
9. 问题页；
10. 决定页；
11. YAML → HTML；
12. Context Pack；
13. Git Diff / 文件变化扫描；
14. Review Pack；
15. Handoff Pack。

---

## 8. MVP 成功标准

当 DeepSpec MVP 完成时，应能做到：

1. 打开一个软件项目；
2. 展示九类规格文档；
3. 点击文档后用 WebView2 显示 HTML；
4. 从 YAML 生成 HTML；
5. 检查文档缺项；
6. 显示红绿灯；
7. 打开 Spec Inspector 查看属性、问题、决定；
8. 生成给 Codex / Claude Code 的 Context Pack；
9. AI 外部开发后扫描 Git Diff；
10. 生成 Review Pack；
11. 生成 Handoff Pack。
