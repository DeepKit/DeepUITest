# DeepKit.top 网站设计规格

> 最后更新：2026-05-10

## 技术方案

- 框架：MkDocs + Material 主题 + 自定义 HTML/CSS
- 部署：自有服务器，静态文件
- 内容管理：Markdown + AI 辅助更新（半年一次）
- 支付：软件端跳转服务器（微信支付，不在网站内完成）

| 用途 | 色值 | 说明 |
|------|------|------|
| 背景 | #FFFFFF | 纯白主背景 |

## 产品卡片设计

每张卡片包含：
- 产品图标（48×48，各产品已有 .ico）
- 产品名（大字）
- 一句话定位（灰色小字）
- 价格标签（右上角）：
  - 橙红底白字：高价产品（¥208+/月）
  - 蓝色底白字：中价产品（¥12-99/月）
  - 绿色底白字：免费
  - 紫色底白字：企业咨询
- 点击整张卡片跳转到产品详情页

## 产品详情页模板

每个产品一个 Markdown 文件，统一结构：

```markdown
# {产品名}

> {一句话定位}

## 解决什么问题

{2-3 句话描述痛点}

## 核心能力

- 能力 1
- 能力 2
- 能力 3

## 截图/演示

{产品截图或 GIF}

## 定价

{价格表}

## 下载

{下载按钮 / GitHub 链接}
```

## 瀑布流排序规则

双列瀑布流，按以下优先级从上到下排列：
1. 高价旗舰（DeepDev、DeepStory、DeepShine）
2. 企业/端口计费（Assayer、DeepCompare、DeepRenew）
3. 低价入口（DeepLaunch、DeepClip）
4. 免费工具（DeepMoveC、DeepSVG、DeepInsight、DeepSync...）
5. 技术底座（DeepBase）
